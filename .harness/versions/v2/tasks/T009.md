# T009: Exported scrubbed-env argv runner

Phase 3 · Model: opus: subprocess construction and env scrub, the single non-git os/exec site (A1, Risk: PDF subprocess) · Depends-on: T000 · Covers: R31, R22

## Brief
Refactor `internal/provider/exec/exec.go` (package `execprov`) so its subprocess logic is one exported,
reusable function, and make `Runner.Complete` use it:

```go
// RunArgv runs argv[0] with argv[1:] directly (no shell), with stdin as standard input and an
// environment of PATH plus the extra "KEY=value" entries only. It returns stdout (capped) and an error.
func RunArgv(ctx context.Context, argv []string, stdin []byte, extraEnv []string, timeout time.Duration, stdoutCap int) ([]byte, error)
```
Rules:
- `argv` empty or `argv[0] == ""` -> `errs.Fatal(errs.BadInput, ...)`; the program is resolved with the
  normal `exec.Command` lookup; it is never wrapped in `sh -c` or similar.
- Environment is exactly `PATH=<current PATH>` plus `extraEnv` (no other variable of the parent leaks).
- `timeout <= 0` means 120 s; on timeout the error says "timed out after <d>"; `cmd.WaitDelay` stays 1 s.
- Non-zero exit -> error containing the exit code and at most 200 bytes of stderr; stdout larger than
  `stdoutCap` -> error "output exceeds"; a missing program -> an error that callers can detect with a new
  exported `IsNotFound(err error) bool` (wraps `exec.ErrNotFound` / `fs.ErrNotExist`).
- Errors returned by `RunArgv` are plain Go errors (wrapped); `Complete` keeps converting them to
  `PROVIDER_ERROR` with the API key redacted exactly as today, and keeps passing the API key env var only
  when `api_key_env` is set. No behaviour of the exec provider changes; all existing exec tests pass.
- This file stays the only non-git importer of `os/exec`.

Tests in `internal/provider/exec/exec_test.go`, top-level `TestRunArgv` (use the test binary re-exec pattern
already in that file for helper programs): stdout returned; env contains only `PATH` and the extra entries
(helper prints its environment; set a marker variable `SLOWHUNCH_LEAK=1` in the test process first and
assert it is absent); an argument `a;echo hacked` arrives as one literal argument (no shell); timeout;
non-zero exit with stderr snippet; output cap; missing program detected by `IsNotFound`; empty argv fails.
