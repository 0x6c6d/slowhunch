# T007: Provider resolution by role and medium

Phase 2 · Model: sonnet: field-wise merge plus wiring through pipeline deps · Depends-on: T001 T006 · Covers: R32, R18

## Brief
Change `internal/provider/provider.go`:
- `Effective(cfg vault.Config, role, medium string) vault.ProviderConfig`: start from `cfg.Provider`, apply
  `cfg.Roles[role]`, then `cfg.Media[medium][role]`; each layer overrides only the fields it sets
  (non-empty `name`, `base_url`, `model`, `api_key_env`; `command` replaced whole when non-empty). An empty
  `medium` skips the media layer.
- `ForRole(cfg, role, medium string) (Provider, error)` builds from `Effective`; unknown role stays
  `BAD_INPUT`. Update every caller (`internal/cli`, `internal/pipeline`, tests).
- `internal/pipeline/add.go` `Deps`: add `ProviderFor func(role, medium string) (provider.Provider, error)`.
  When it is set the pipeline obtains the provider for each call with the item's medium; when it is nil the
  existing `Providers` map is used (so v1 tests with the fake provider keep working unchanged). The cli sets
  `ProviderFor` from `provider.ForRole(cfg, role, medium)` and caches one provider per (role, medium).
  The `Author` string (`agent:<provider>/<model>`) of written atoms reflects the extract provider actually
  used for the item.

Tests: `TestResolveV2` in `internal/provider/provider_test.go`, table-driven: provider only; role override of
`model` only keeps provider `base_url`; media override of `model` beats the role override while the role's
`api_key_env` survives; media override for another medium has no effect; `command` replaced whole; empty
medium; unknown role fails. Add one pipeline test `TestResolveV2Pipeline` in `internal/pipeline/` showing that
with `ProviderFor` set, a `poem` item's extract call goes to the provider chosen for (`extract`, `poem`) and
an `article` item's to the default one (two fake providers).

## Verification
`.harness/verify/v2/T007.sh` exits 0. It runs `TestResolveV2` and `TestResolveV2Pipeline` and the full
provider, pipeline and cli packages, and checks that `ForRole` takes a medium argument.
