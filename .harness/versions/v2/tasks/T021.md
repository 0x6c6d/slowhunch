# T021: sync command, --sync and dry-run BEHIND

Phase 5 · Model: opus: pull/push on demand and dry-run guarantees against a live remote (Risk: pull/rebase, push) · Depends-on: T020 · Covers: R36, R37, R12 (git behind)

## Brief
In `internal/cli` (new `cmd_sync.go` plus the run helper of the pull/push tasks):

- `slowhunch sync` (summary `pull then push the vault's git remote`): requires a vault with the remote
  `git.remote`, else `NOT_FOUND` with hint `git remote add origin <url>` (the literal hint text). Pulls
  (`PullRebase`, skipped when the branch has no upstream or with `--no-pull`), then pushes
  (`Push(remote, branch)`, regardless of `git.push`; skipped with `--no-push`). Writes no vault file and
  makes no commit of its own. Result `{pulled, pushed}` (int, bool). Pull `CONFLICT` -> exit 4 with the
  rebase aborted; `PULL_FAILED`/`PUSH_FAILED` -> that error, exit 1.
- Read-only commands `search get list stats review verify lint` never pull; with the new global flag
  `--sync` they pull first (same rules and outcomes as a write's pull, `pulled` added to the JSON result
  when it is an object) and then run. `--sync` on any other command is accepted and ignored.
- `--dry-run` on a vault-changing command never pulls or pushes. It reports `git.behind` = `Repo.Behind()`
  (from the already-fetched upstream ref, no network; 0 without upstream) and, when behind > 0, a `BEHIND`
  warning (`errors` for `add`/`collide`, else `warnings`); exit 0; the vault and `.git` refs stay
  byte-identical. `report.GitInfo` gets `Behind int json:"behind"`.

Tests in `internal/cli/`: `TestSyncPullPush` (B with a new local commit and A's pushed commit: `sync`
pulls 1 and pushes, bare repo has both, no file written beyond the pulled ones, `git status` clean);
`TestSyncNoRemote` (`NOT_FOUND` with the hint); `TestSyncFlags` (`--no-pull`, `--no-push`);
`TestDryRunBehind` (after the test runs `git fetch` in B, `--dry-run create ...` reports `behind: 1` and a
`BEHIND` warning, HEAD and every file unchanged); `TestSearchSync` (`search` leaves B's HEAD as is;
`search --sync` pulls and its results include A's note).

## Verification
`.harness/verify/v2/T021.sh` exits 0. It runs the five tests and the cli package; with the built binary it
checks `sync` pulls and pushes against a local bare remote, `--dry-run` reports `BEHIND` with a
byte-identical tree, and (negative) `sync` on a vault without a remote fails `NOT_FOUND`.
