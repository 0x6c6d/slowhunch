# T003: Git policy tests: force and rewrite ban

Phase 1 · Model: opus: replaces a security policy test (Consequential assumption A20, Risk: git side effects) · Depends-on: T000 · Covers: R39, R21 (removed clause), R22

## Brief
v1 bans the words `git push`/`git pull`/`"push"`/`"pull"` in non-test code (`TestNoForbiddenGit` in
`internal/policy/policy_test.go`). v2 removes that ban (spec: removed R21 clause) because `internal/gitops`
will run `pull --rebase --autostash` and plain `push`. Replace it, in `internal/policy/policy_test.go` only, by:

1. `TestNoForceGit`: scans every non-test `.go` file of the module (reuse `goFiles`, the AST string-literal
   walk and the line scan already in the file) and fails on:
   - text (any line, comments included) matching `--force` (covers `--force-with-lease`), `reset --hard`,
     `filter-branch`, `rebase -i`, `rebase --interactive`, `push -f`;
   - string literals equal to `--force`, `--force-with-lease`, `filter-branch`, `--interactive`;
   - string literals that look like a force refspec: start with `+` and continue with a non-space
     character, e.g. `+main`, `+refs/heads/x`, `+HEAD:main` (a literal that is exactly `+` or starts with
     `+ ` is fine);
   - inside `internal/gitops/` non-test files only, additionally the literals `-f`, `--hard`, `reset`, `-i`,
     `fetch`, `update-ref`, `replace`.
2. `TestGitOnlyGitops`: fails when any non-test file outside `internal/gitops/` contains a call
   `exec.Command(...)` or `exec.CommandContext(...)` whose program argument is the string literal `git`
   (AST check on the call's selector and argument), or a string literal `git` passed to `exec.LookPath`.
   Keep `TestExecOnlyGitopsAndExecProvider` (os/exec import allowlist) as it is.
3. Delete `TestNoForbiddenGit` and its `forbiddenRe`/`forbiddenLits`.

Both new tests must pass on the current tree. Do not change any non-test code. Each test reports file and
line for every hit.

## Verification
`.harness/verify/v2/T003.sh` exits 0. It runs both tests, checks the old test is gone, and (negative) plants
temporary files with a `"push", "--force"` argv, a `+main` refspec literal and an `exec.Command("git", ...)`
outside gitops, each of which must make the matching policy test fail; the planted files are removed.
