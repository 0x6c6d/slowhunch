# Plan v2: synthesis, richer input, provider control, git sync

_Source: `.harness/versions/v2/spec.md` (2026-11-05). Core plan: `.harness/Plan.md`. Generated by an AI planner._

## Scope
**In scope for this version:** R25-R40 (`collide`, `review`, wildcard lane, `keep`, `add --from`, PDF via `pdf.command`,
per-role/per-medium providers, per-medium caps, pull/push/`sync`, force-free git policy, skill + README); changed R7, R12,
R17, R18, R21, R22, R23; removed R21 clause and its v1 push/pull word-ban policy test.
**Explicitly deferred:** everything in spec §7 (`docs/`, `CONTRIBUTING.md`, `examples/`, `send_policy` other than
`excerpt_only`, MCP, embeddings, `prompts diff`, vault import, OCR/vision/audio, scheduler/daemon, automatic conflict
resolution, third-party packages); `git fetch` (not allowed by spec §5).

## Architecture changes
- **internal/vault (changed)**: config adds `collide{max_cosine,aesthetic_weight,max_pairs}`, `review.stale_days`,
  `place.wildcard_share`, `pdf.command`, `media.<medium>.<role>`, `caps.by_medium.<medium>{runs_per_day,tokens_per_run}`,
  `git{pull,require_pull,push,remote,branch}`; `state.json` adds `runs_by_day`; topic body append helper for `keep`.
- **internal/errs, internal/report (changed)**: codes `CAP_REACHED` (exit 2), `PULL_FAILED`/`PUSH_FAILED` (exit 1),
  `BEHIND`; report fills `wildcards`/`collisions`, `git` adds `pulled pushed behind`; `stats` adds `collide` tokens.
- **internal/provider (changed)**: role `collide` + `prompts/collide.md`; field-wise resolution `media.<medium>.<role>`
  > `roles.<role>` > `provider`; `tokens_per_run` meter. `provider/exec` exports its scrubbed-env argv runner
  (timeout param), the only non-git `os/exec` site; `intake` reads `.pdf` through it (`pdf.command`).
- **internal/synth (new)**: collide pair selection (cosine filter, aesthetic weight, reserved `asserts` x `reads`
  cross-medium quota, deterministic order, skip pairs already in proposals), proposal building; `review` queries.
- **internal/pipeline (changed)**: batch runner (`--from`, one run id, per-entry reports), wildcard lane, cap checks.
- **internal/gitops (changed)**: `PullRebase` (`pull --rebase --autostash`, `rebase --abort` on conflict), `Push`,
  `Behind` (`rev-list --count HEAD..@{u}`), `HasRemote`/`Upstream`; still argv only, no fetch/force/reset.
- **internal/cli (changed)**: commands `collide review keep sync`; flags `add --from`, `--push --no-push --no-pull
  --sync`; one run wrapper does resume → pull → index rebuild → command → commit → push for every vault-changing command.
- **internal/policy (changed)**: v1 push/pull word ban replaced by the R39 force/rewrite ban + git-call-site test.

## Build Phases
### Phase 0: Preflight
- **Checks:** `test -z "$(git status --porcelain)"`; `make check`; `git --version`; `go version` (`command -v pdftotext` informational only)
### Phase 1: Config, codes and `review` (walking skeleton)
- **Goal:** new config keys with defaults, new error codes/exits, and the model-free `review` through cli + vault.
- **Key deliverables:** config structs + defaults, errs codes, `internal/synth` review queries, `review` command + skill line.
- **Exit criterion:** `go test ./internal/vault/ ./internal/errs/ ./internal/cli/ -run 'TestConfigV2|TestErrsV2|TestReview' -v` passes.
### Phase 2: Providers and caps (R32, R33, R18, R23)
- **Goal:** field-wise provider resolution, `collide` role + prompt, per-medium caps, `stats` collide tokens.
- **Exit criterion:** `go test ./internal/provider/... ./internal/pipeline/ ./internal/report/ -run 'TestResolveV2|TestCaps|TestStatsCollide' -v` passes.
### Phase 3: Input (R30, R31, R28, R7)
- **Goal:** PDF via runner, batch `add --from`, wildcard lane; R7 tests updated (`.pdf` no longer always `UNSUPPORTED`).
- **Exit criterion:** `go test ./internal/... -run 'TestPDF|TestBatch|TestWildcard' -v` passes.
### Phase 4: Synthesis (R25, R26, R29, R12)
- **Goal:** `collide` selection + proposals + report `collisions`; `keep` topic append.
- **Exit criterion:** `go test ./internal/synth/ ./internal/cli/ -run 'TestCollide|TestKeep' -v` passes.
### Phase 5: Git sync (R34-R39, R21, R22)
- **Goal:** gitops pull/push/behind/abort, run wrapper integration for all vault-changing commands, `sync`, `--sync`,
  replaced policy tests (removed R21 clause).
- **Exit criterion:** `go test ./internal/gitops/ ./internal/cli/ ./internal/policy/ -run 'TestPull|TestPush|TestSync|TestDryRunBehind|TestRebaseConflict|TestNoForceGit|TestGitOnlyGitops' -v` passes.
### Phase 6: Docs (R40)
- **Goal:** `skill` <= 60 lines naming new commands; README sections; README test extended.
- **Exit criterion:** `go test ./internal/cli/ -run 'TestSkill|TestReadme' -v` passes and `make check` exits 0.

## Global Definition of Done
Each `-run` line must print at least one `--- PASS` for every named pattern and no `--- FAIL`.
1. `go test ./... -run 'TestCollide' -v`: cosine <= 0.15 only, reserved cross-medium pairs, aesthetic weight, `max_pairs` + `capped`, valid proposals with `items`/`bears_on`, 2nd run writes nothing, notes/hunches unchanged.
2. `go test ./... -run 'TestReview' -v`: exact stale/orphan/unplaced lists, tree hash unchanged.
3. `go test ./... -run 'TestWildcard' -v`: 10 rejected keep exactly 1 tagged `wildcard`; 1 rejected keeps 0; all in `wildcards`.
4. `go test ./... -run 'TestKeep' -v`: named + nearest topic append with correct rev; missing ids, no topic, secret, 2,001 chars fail, nothing written.
5. `go test ./... -run 'TestBatch' -v`: 3 written, 2 errors with line numbers, 1 commit; 51 entries `TOO_LONG`.
6. `go test ./... -run 'TestPDF' -v`: helper `pdf.command` adds `article`; missing/failing = `UNSUPPORTED` + hint; scrubbed env, no shell.
7. `go test ./... -run 'TestResolveV2|TestStatsCollide|TestCaps' -v`: field-wise precedence; `stats` shows `collide` tokens; `runs_per_day` 1 refuses run 2 with `CAP_REACHED`, nothing written; `tokens_per_run` marks rest.
8. `go test ./... -run 'TestPull|TestPush' -v`: two clones + bare remote; pushed change pulled before write and visible to placement; `git.push` false pushes nothing; `--no-pull`/`--no-push`; `pulled`/`pushed` reported; failed push retried next run.
9. `go test ./... -run 'TestSync|TestDryRunBehind|TestSearchSync' -v`: `sync` pull+push, no files written, no remote `NOT_FOUND`; dry-run `BEHIND` + byte-identical tree; `search` no pull, `search --sync` pulls.
10. `go test ./... -run 'TestRebaseConflict|TestPullFailed' -v`: `CONFLICT` exit 4, rebase aborted, files unchanged; removed remote = `PULL_FAILED` continue; `require_pull` stops before write.
11. `go test ./internal/policy/ -run 'TestNoForceGit|TestGitOnlyGitops' -v`: no force/rewrite forms, git only in gitops.
12. `go test ./internal/cli/ -run 'TestSkill|TestReadme' -v`: skill <= 60 lines with new commands; README grep of every new command/key; Quick start passes (README task verification script exits 0).
13. `make check` exits 0 (all v1 tests still pass).
