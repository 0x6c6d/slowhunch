## Build Phases
### Phase 0: Preflight
- **Checks:** `go version | grep -q 'go1.27'` · `git --version` · `make --version` · `gofmt -h 2>&1 | grep -q usage`
  · `test -z "$(git status --porcelain)"` · `test "$(git rev-parse --show-toplevel)" = /home/sa/workspace/code/slowhunch`
  · `test ! -e go.sum` (stdlib only, no third-party modules).
- `.gitignore` coverage (`git check-ignore -q bin/x`) is a Phase 1 exit check, because `bin/` is a v1 deliverable (Assumption 14).
### Phase 1: Scaffold (walking skeleton)
- **Goal:** binary builds, CLI dispatch, JSON envelope, error/exit codes, minimal `init` + `skill`.
- **Key deliverables:** `go.mod`, `Makefile` (build/test/lint/check), `LICENSE`, `.gitignore` `bin/`, `cmd/slowhunch/main.go`, `internal/cli` skeleton.
- **Exit criterion:** `make check && git check-ignore -q bin/x && d=$(mktemp -d) && ./bin/slowhunch init "$d/v" --json | grep -q '"schema": *1' && test -d "$d/v/.slowhunch"`
### Phase 2: Vault core
- **Goal:** frontmatter subset, five types, ids, locators, `rev`, single write path, audit log, test guard, gitops.
- **Key deliverables:** `internal/frontmatter`, `internal/vault`, `internal/gitops` with tests (round-trip, rev stable/changes, id examples + `-2`, `..`/symlink refusal, dirty-file `CONFLICT`, exact-path commit).
- **Exit criterion:** `go test ./internal/frontmatter/... ./internal/vault/... ./internal/gitops/...`
### Phase 3: Agent interface
- **Goal:** full `init` (R1) and CRUD/graph/hunch/`source facts` commands with `--json`, commit per run.
- **Exit criterion:** `go test ./internal/cli/... -run 'TestInit|TestCRUD|TestHunch|TestSourceFacts|TestExitCodes|TestSchema'`
### Phase 4: Search and integrity
- **Goal:** TF-IDF index/search, `lint`, `verify`, `stats`, `skill` ≤ 60 lines.
- **Exit criterion:** `go test ./internal/search/... ./internal/report/... ./internal/cli/... -run 'TestSearch|TestLint|TestVerify|TestStats|TestSkill'`
### Phase 5: Providers and intake
- **Goal:** `Provider` + registry, `openai-compatible`, `exec`, JSON repair, embedded prompts, intake normalization, fencing, secret detector.
- **Exit criterion:** `go test ./internal/provider/... ./internal/intake/...`
### Phase 6: `add` pipeline
- **Goal:** gate → extract → place → write → report, idempotency, `--dry-run`, crash resume, git commit.
- **Exit criterion:** `go test ./internal/pipeline/... ./internal/cli/... -run 'TestAdd|TestGate|TestExtract|TestPlace|TestReport|TestDryRun|TestIdempotent|TestResume|TestFencing|TestSecret'`
### Phase 7: Hardening and README
- **Goal:** 2,000-atom perf test, no-push/pull/force grep test, exit-code coverage, README with tested quickstart.
- **Exit criterion:** `make check && go test ./... -run 'TestPerf|TestNoForbiddenGit|TestReadmeQuickstart' -count=1`
