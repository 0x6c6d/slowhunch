## Brief

Existing functions: `Add`, `Decide`, `Place`, `BuildNeighbours`, `(*Txn).Touch/PutDoc`, `vault.Validate`, `report.Link`, `search` cosine helpers. Existing files are always updated with their current rev and only by adding data; `evidence` is never rewritten.

- `duplicate` (never for `reads`): write no new note; add to the target note's `corroborations` list the entry `"<YYYY-MM-DD> <source-id>"` (skip if identical entry exists); `Report.Corroborations` gets `{atom: Link(target), source: Link(sid), date}`; counts `duplicates`.
- `contradicts`: write the new note with `status: contradiction` and `links: [target]` (its `source` links the other side); add a hunch evidence entry `{date, note: <new id>, relation: weakens}` to every hunch in the target's `bears_on` plus `--hunch` (Plan assumption 7), only for hunches that exist; `Report.Contradictions` gets `{atom: Link(new), contradicts: Link(target), hunches: [Link(h)...], cosine}`. Contradictions are listed first in the report (key order already guarantees it).
- `rereads`: new note with `rereads: [target]` (already written by the core; keep it).
- Echo (`Decision.Echo`): the note is written as `new`; `Report.Echoes` gets `{atom: Link(new), echoes: Link(EchoOf), cosine}`; counts `echoes`.
- Hunch evidence (Plan assumption 6): for each written note (actions new, extends, rereads), add `{date, note, relation: supports}` to the `--hunch` hunch and to every hunch in state `open` or `warming` whose `question` has TF-IDF cosine ≥ `place.contradict_cosine` with the note's claim + evidence (index over hunch questions); add each such hunch id to the note's `bears_on`. A hunch in state `open` becomes `warming`. One entry per (hunch, note). Each entry → `Report.HunchesMoved` `{hunch: Link(h), note: Link(n), relation}`.
- Every file to be modified (targets, hunches) is `Touch`ed together with the new files before the first write, so a dirty foreign file aborts the whole run with CONFLICT before anything is written.
- All writes still end in one commit; the commit ids list the new notes, the source and modified hunches/notes.
