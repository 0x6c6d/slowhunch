# T028: openai-compatible provider

Phase 5 · Model: opus: the only network egress and the only place a secret is read (security Risk items) · Depends-on: T027 · Covers: R19 (openai-compatible), R22 (egress only to base_url, secrets), R18

## Brief
Create package `openai` in `internal/provider/openai/` (`openai.go` + `openai_test.go`). This is the only non-test file in the product that may import `net/http`.

API (exact):
```go
type Client struct {
    BaseURL, Model, APIKeyEnv string
    HTTP    *http.Client      // Timeout 60 s by default
    Backoff time.Duration     // wait before the single retry; default 1 s (tests set it small)
}
func New(cfg vault.ProviderConfig) (provider.Provider, error)
func (c *Client) Complete(ctx context.Context, req provider.Request) (provider.Response, error)
func init() { provider.Register("openai-compatible", New) }
```
Behaviour:
- `New`: `base_url` must parse as an absolute `http` or `https` URL with a host (else `errs.Fatal(errs.BadInput, ...)`); `model` required. No other host is ever contacted: the request URL is exactly `strings.TrimRight(base_url, "/") + "/chat/completions"`.
- Request: `POST`, `Content-Type: application/json`, body `{"model", "messages": [{"role": "system", "content": System}, {"role": "user", "content": User}], "temperature": 0, "response_format": {"type": "json_object"}, "max_tokens": MaxTokens (omit if 0)}`. Header `Authorization: Bearer <key>` only when the env var named by `api_key_env` is non-empty; the key is read at call time with `os.Getenv` and never stored in a struct field, logged or returned.
- Response: `choices[0].message.content` → `Text`; `usage.prompt_tokens` / `usage.completion_tokens` → tokens; missing `usage` → 0 (not an error). Missing choices → PROVIDER_ERROR.
- Retry: on HTTP 429 or 5xx, wait `Backoff` (respect ctx), retry exactly once; a second failure → PROVIDER_ERROR. Other non-2xx → PROVIDER_ERROR without retry. Network errors → PROVIDER_ERROR (one retry allowed too).
- Errors: message includes the status and at most 200 bytes of the response body, with every occurrence of the key replaced by `***` (redact before building any error string). No redirect following to other hosts (`CheckRedirect` returns an error).

Tests (only `httptest.NewServer`, never a real host): `TestOpenAIRequest` (path `/chat/completions`, method, JSON body fields including `temperature` 0 and `response_format.type`, auth header `Bearer test-key` via `t.Setenv`), `TestOpenAINoKey` (no Authorization header when env empty), `TestOpenAIRetry429` (429 then 200 → success, exactly 2 requests), `TestOpenAIRetryOnce` (500 twice → PROVIDER_ERROR, exactly 2 requests), `TestOpenAINoRetry400` (exactly 1 request), `TestOpenAIUsageMissing` (tokens 0), `TestOpenAIRedact` (a 401 body echoing the key → error text contains `***`, not the key), `TestOpenAIRepair` (server returns invalid JSON content then valid; `provider.CallJSON` makes exactly 2 requests), `TestOpenAIBadBaseURL` (`file:///x`, `ftp://h`, empty → error), `TestOpenAITimeoutDefault` (`HTTP.Timeout == 60*time.Second`).

## Verification
`.harness/verify/v1/T028.sh` exits 0. It runs the named tests and checks that no other non-test file imports `net/http`; negatives: a non-http base URL is refused, and an error message never contains the API key.
