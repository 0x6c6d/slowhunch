# T005: Frontmatter subset parser, canonical writer, rev

Phase 2 · Model: opus: parses untrusted hand-editable files; schema choice is a Risk item and Consequential (parse failures are never auto-fixed) · Depends-on: T002 · Covers: R2, R3, R5 (rev)

## Brief
Create `internal/frontmatter` (package `frontmatter`): a small, strict, YAML-like subset, parsed and written by our own code (no YAML library). Every vault file is `---\n<fields>---\n<body>`.

API (exact):
```go
type Field struct { Key string; Value any } // string | []string | []map[string]string
type Doc struct { Fields []Field; Body string }
func Parse(b []byte) (*Doc, error)              // errors are *errs.Error with code BAD_INPUT naming the line
func (d *Doc) Bytes() []byte                     // canonical form
func (d *Doc) Get(key string) (any, bool)
func (d *Doc) GetString(key string) string       // "" if absent or not a scalar
func (d *Doc) GetList(key string) []string       // nil if absent or not a list
func (d *Doc) GetMaps(key string) []map[string]string
func (d *Doc) Set(key string, v any)             // replace in place, or append at the end
func (d *Doc) Delete(key string)
func (d *Doc) Clone() *Doc
func Rev(d *Doc) string                          // first 6 hex chars of sha256 of Bytes() of a clone without the "rev" field
func LineOf(b []byte, key string) int            // 1-based line of a top-level key in raw bytes, 0 if absent
```
Grammar (the only accepted input; canonical output uses exactly this):
```
---
id: crafts-larkin-trees-lines-1-2
claim: "Short: quoted because of the colon"
tags: []
bears_on:
  - h1
evidence:
  - date: 2026-11-05
    note: crafts-larkin-trees-lines-1-2
    relation: supports
---
<body>
```
- Keys match `^[a-z_][a-z0-9_]*$`; top-level key order is preserved; duplicate keys are an error.
- Scalars: plain if they match `^[A-Za-z0-9_./@+-][A-Za-z0-9 _./@+()-]*$` and do not end in a space; otherwise a JSON double-quoted string (write with `encoding/json`, HTML escaping off; read with `json.Unmarshal`). Empty scalar is `""`. All scalars are strings (numbers too). Multi-line text is a quoted scalar with `\n`.
- Lists: `key: []` when empty, else `key:` followed by lines `  - <scalar>`. `[]` parses as an empty `[]string`; `GetList` and `GetMaps` both return an empty (non-nil) slice for it, and an empty `[]map[string]string` is written as `[]` too.
- List of maps: `key:` followed by items `  - k: v` with continuation lines `    k: v`; keys inside an item are written sorted; values are scalars only. An item line whose content looks like `k: v` is a map item; a scalar list item containing `: ` is always quoted by the writer, so there is no ambiguity.
- Rejected with BAD_INPUT: missing opening or closing `---`, tabs in the frontmatter, block scalars (`|`, `>`), flow maps or flow lists other than `[]`, anchors/aliases/tags (`&`, `*`, `!`), comments, nested structures deeper than list-of-maps, bad indentation, unterminated or invalid quoted strings, a `key:` with no items under it, a mixed list (scalars and maps), duplicate keys, CR characters.
- Body: everything after the closing `---\n`. Canonical body: trailing whitespace trimmed and exactly one `\n` appended when non-empty; empty body stays empty.
- `Bytes()` of a parsed canonical file equals the input bytes; `Parse(d.Bytes())` equals `d` when `d.Body` is canonical.

Tests (`internal/frontmatter/frontmatter_test.go`): `TestRoundTrip` (one realistic doc for each type: note, source, hunch with evidence maps, proposal, topic with body; byte-identical round trip; quoted scalars with `:`, `#`, `"`, newline, unicode), `TestRevStable` (no-op parse/write keeps rev; rev ignores the existing rev line), `TestRevChanges` (a field patch changes rev), `TestRejects` (table of every rejected construct above), `TestLineOf`.
