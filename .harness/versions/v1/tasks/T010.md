# T010: Transactions: conflict check, pending-path resume, one commit per run

Phase 2 · Model: opus: crash resume (Consequential assumption 12), dirty-file CONFLICT and exact commits are data-loss and git Risk items · Depends-on: T008, T009 · Covers: R13 (resume), R21, R12 (dry-run writes nothing)

## Brief
Add `internal/vault/txn.go` (package `vault`) + tests. Every vault-changing command runs inside one `Txn` and ends with one commit. Package `vault` must NOT import `gitops`; it talks to git through this interface (`*gitops.Repo` satisfies it). Tests may live in package `vault_test` and use the real `internal/gitops`.

API (exact):
```go
type Committer interface {
    Dirty(paths []string) ([]string, error)
    Commit(paths []string, subject, body string) (string, error)
}
type TxnOptions struct {
    RunID          string             // "" -> NewRunID(Now())
    DryRun         bool
    NoCommit       bool               // --no-commit or config git.commit=false
    Committer      Committer          // nil = git unavailable: behave like NoCommit
    PromptVersions map[string]string
    Now            func() time.Time   // nil -> time.Now
}
type Txn struct { /* unexported */ }
func NewRunID(now time.Time) string   // "YYYYMMDD-HHMMSS-" + 6 random hex (crypto/rand)
func (v *Vault) Begin(command string, o TxnOptions) (*Txn, error)
func (t *Txn) RunID() string
func (t *Txn) Touch(paths ...string) error
func (t *Txn) WriteFile(rel string, data []byte) error
func (t *Txn) PutDoc(rel string, d *frontmatter.Doc, expectRev string) (string, error)
func (t *Txn) Move(from, to string) error
func (t *Txn) Remove(rel string) error
func (t *Txn) Written() []string          // sorted paths written (or planned, in dry-run) by this txn
func (t *Txn) Commit(ids []string, counts string) (string, error)
```
Semantics:
- `Begin` loads `State`; its `Pending` paths (left by a crashed earlier run) are owned by this run.
- `Touch(paths)`: unless commit is disabled, ask `Committer.Dirty(paths)`; any dirty path not in `Pending` and not already written by this txn → `errs.New(errs.Conflict, "uncommitted changes in <paths>", "commit or revert them first")` with `Extra{"paths": [...]}` and exit 4. Callers Touch every path they will write before writing anything. `WriteFile`/`PutDoc`/`Move`/`Remove` Touch their own paths automatically (both paths of a move).
- Before each real write: add the path(s) to `State.Pending` and `SaveState` (so a crash leaves a record), then delegate to the `Vault` method. `.slowhunch/state.json`, `.slowhunch/audit.log` and `.slowhunch/reports/` are never added to pending or commits (they are git-ignored by `init`).
- Dry-run: writes and moves are recorded in `Written()` but nothing on disk changes (PutDoc still performs the EXISTS / CONFLICT_REV checks and returns the would-be rev); `Commit` returns `""` and writes no audit line and no state.
- `Commit(ids, counts)`: if commit is enabled, commit `Written() ∪ Pending` with subject `slowhunch: <command> <ids joined by space; more than 5 → first 5 then "+N more"> (<counts>)` and body lines `run: <run-id>` and, if any, `prompts: gate=<v>, extract=<v>, place=<v>` (sorted keys). Then clear `Pending`, save state, and append an audit line (`Time` RFC 3339, run id, command, paths, prompt versions, commit hash). If commit is disabled: no commit, clear `Pending`, audit line with empty commit. Return the hash (or `""`).

Tests: `TestTxnConflict` (a foreign modified tracked file that the run would touch → CONFLICT before anything is written; untouched dirty files do not matter), `TestTxnCommitExact` (commit contains exactly the written files; an unrelated modified file stays uncommitted; subject format), `TestTxnResume` (write two files, do not call Commit, drop the Txn; a new Txn writing a third file commits all three in one commit and clears pending; the earlier files are not a CONFLICT), `TestTxnDryRun` (hash of every file under the vault, including `.slowhunch`, identical before and after; no new commit), `TestTxnNoCommit`, `TestRunID`.
