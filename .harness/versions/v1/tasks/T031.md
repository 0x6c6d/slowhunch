# T031: Intake normalization and text hash

Phase 5 · Model: sonnet: deterministic stdlib text transform with table tests · Depends-on: T001 · Covers: R8

## Brief
Add `internal/intake/normalize.go` + `normalize_test.go` (package `intake`; the package may already contain `read.go`). No model, no I/O.

API (exact):
```go
func Normalize(text, medium string) string
func TextHash(normalized string) string     // full lowercase hex sha256 of the normalized text
```
Rules for every medium except `code`, applied once, in this order:
1. Line endings: `\r\n` and `\r` → `\n`.
2. Characters: U+00A0, U+202F, U+2007 (no-break spaces) → space; U+2018, U+2019, U+201B → `'`; U+201C, U+201D, U+201F → `"`; U+2014 (em dash) → `--`; U+2013 (en dash) → `-`; U+2026 → `...`; remove U+FEFF and U+200B.
3. Per line: tabs → space, runs of spaces → one space, trim both ends.
4. Lines: drop leading and trailing empty lines; collapse runs of more than one empty line into one empty line. Line breaks are otherwise kept exactly (poems keep every line).
For `code`: only step 1 and dropping trailing empty lines; indentation, tabs, quotes and inner whitespace are untouched.

Properties: `Normalize(Normalize(x, m), m) == Normalize(x, m)` for every medium; the result has no trailing newline. Line numbering is not done here (storage uses `vault.FormatInbox`, which another task provides).

Tests: `TestNormalizeTable` (curly quotes, em/en dash, NBSP, CRLF, tabs, blank-line runs, a 2-line poem keeps its break, code keeps indentation and tabs), `TestNormalizeIdempotent` (several inputs × mediums), `TestTextHash` (known sha256 of `"abc"` = `ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad`).
