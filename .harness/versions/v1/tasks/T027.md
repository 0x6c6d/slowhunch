# T027: Provider interface, registry, fake, JSON call with repair

Phase 5 · Model: opus: validates untrusted model output (R20, never instructions or paths) and defines the interface every provider follows · Depends-on: T012, T003 · Covers: R18, R20

## Brief
Add to package `provider` (`internal/provider/provider.go`, `jsoncall.go` + tests) and create package `fake` (`internal/provider/fake/fake.go`, test-support code used by later tests). The package already contains `prompts.go` (keep it). Import `vault` only for `vault.Config` / `vault.ProviderConfig`.

API (exact):
```go
type Request struct { Role, Medium, System, User string; MaxTokens int }
type Response struct { Text string; TokensIn, TokensOut int }
type Usage struct { TokensIn, TokensOut int }
type Provider interface { Complete(ctx context.Context, req Request) (Response, error) }
type Factory func(cfg vault.ProviderConfig) (Provider, error)
func Register(name string, f Factory)                      // panics on duplicate name
func New(cfg vault.ProviderConfig) (Provider, error)       // unknown name -> errs.Fatal(errs.Unsupported, "unknown provider <name>", "use openai-compatible or exec")
func ForRole(cfg vault.Config, role string) (Provider, error)   // cfg.Roles[role] fields override cfg.Provider fields when non-empty; role must be gate, extract or place
func Effective(cfg vault.Config, role string) vault.ProviderConfig
func CallJSON(ctx context.Context, p Provider, req Request, out any, validate func() error) (Usage, error)
```
`CallJSON` rules:
- Call `p.Complete`. A transport/provider error → `errs.New(errs.ProviderError, <message>, ...)` immediately (no repair; providers do their own transport retry).
- Take the reply text, strip surrounding whitespace and one optional surrounding Markdown code fence (```` ``` ```` or ```` ```json ````), require it to be exactly one JSON object, `json.Unmarshal` into `out`, then run `validate` (may be nil).
- On a parse or validation failure, call once more with `User` = original user + `"\n\nYour previous reply was invalid: <error, at most 200 chars>. Reply with exactly one JSON object and nothing else."`; on a second failure → `errs.New(errs.ProviderError, "invalid model output after one repair: ...", "")`. Never a third call.
- Returned `Usage` sums both calls. The reply text is never executed, never used as a path, never logged.

`fake` package:
```go
type Fake struct {
    Handler func(req provider.Request) (provider.Response, error) // used if set

func (f *Fake) CallsFor(role string) []provider.Request
```
