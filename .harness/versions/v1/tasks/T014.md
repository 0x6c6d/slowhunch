Phase 3 · Model: sonnet: CRUD command on top of the existing write path · Depends-on: T006, T011, T013 · Covers: R14 (create, get), R2, R3, R4, R21 (commit per run)

## Brief
Add `internal/cli/docjson.go`, `internal/cli/cmd_create.go`, `internal/cli/cmd_get.go` + tests. Use the helpers `env.openVault()`, `env.begin(v, cfg, cmd)`, `env.today()`, `(*Vault).LoadIndex`, `vault.Validate`, `vault.Folder`, `vault.NoteBody`, `vault.UniqueID`, `vault.AtomID`, `vault.KebabID`, `vault.Slug`, `vault.SourceID`, `(*Txn).PutDoc/Commit`, `frontmatter.Doc`.

`docjson.go`:
```go
func docFromJSON(fields map[string]any) (*frontmatter.Doc, error) // string/number/bool -> scalar string; []string-like -> list; []object -> list of maps (scalar values); nested objects -> BAD_INPUT
func docToJSON(d *frontmatter.Doc) map[string]any                  // scalars as strings, lists as arrays, maps as arrays of objects
```
`create <type> --data <json|-> [--id ID]` (`--data -` reads JSON from stdin):
- `<type>` must be one of note, source, hunch, proposal, topic (else BAD_INPUT). JSON must be an object; an optional `"body"` key sets the body (ignored for notes); keys `id type created updated rev` in data are rejected (BAD_INPUT).
- Id: `--id` (must equal `vault.Slug(id, 120)`, else BAD_INPUT) or derived: hunch `KebabID(question)`, proposal `KebabID(idea)`, topic `Slug(title, 60)`, source `SourceID(medium, author, title, title+url)`, note `AtomID(stance, source, locator, claim)`; then `UniqueID` against the index and existing files.
- Sets `id`, `type`, `created`/`updated` = today, writer = `author` (or `added_by` for sources) defaulting to `human` when absent, and for notes `status: active` if absent and the body `NoteBody(claim, evidence)`. Field order: `id type created updated author|added_by rev` first, then data keys in sorted order.
- `vault.Validate` before writing (BAD_INPUT on failure, nothing written). Write with `txn.PutDoc("<folder>/<id>.md", doc, "")` and commit (`ids [id]`, counts `created: 1`).
- Result: `{"id", "type", "path", "rev", "git": {"commit"}}`.

`get <id>`: NOT_FOUND if not in the index. Result: `{"id", "type", "path", "rev", "fields": docToJSON(doc), "body", "backlinks": [...]}`. Text mode prints the raw file.

Tests (`internal/cli/cmd_create_test.go`, temp vault via `Run(init)` and `--vault`): `TestCRUDCreateGet` (create a source, a note with `source`, a hunch, a proposal, a topic; get each back; note file body is the claim line plus blockquote; one commit per create whose subject starts `slowhunch: create`), `TestCRUDCreateCollision` (same hunch question twice → second id ends `-2`), `TestCRUDCreateInvalid` (bad stance, unknown field, confidence on a `crafts` note, bad JSON → exit 2, nothing written, no commit), `TestCRUDGetMissing` (NOT_FOUND exit 2).
