# T035: Place step: neighbours, model verdict, code decision

Phase 6 · Model: opus: the place decision code is named as opus work in the routing policy (model output must never decide writes on its own) · Depends-on: T033, T021 · Covers: R11, R22 (send policy: capped note excerpts only)

## Brief
Add `internal/pipeline/place.go` + `place_test.go`. Use `pipeline.Atom`, `Item`, `Header`, `provider.CallJSON`, `intake.Fence`, `vault.PlaceConfig`, `search.Build/Neighbours/Query/Cosine/DocVector`.

API (exact):
```go
type Neighbour struct { ID string; Cosine float64; Excerpt string; Aesthetic bool; Stance string; Tags []string; Far bool }
type Verdict struct { Verdict string `json:"verdict"`; Target string `json:"target"`; Reason string `json:"reason"` }
type Decision struct { Action, Target string; Cosine float64; Echo bool; EchoOf string; Reason string }  // Action: new extends duplicate contradicts rereads
type Candidate struct { ID, Text, Evidence, Stance string; Tags []string; Aesthetic bool }   // an existing note (from notes/ only)
func CapExcerpt(s string, n int) string   // at most n runes; rune-safe
func BuildNeighbours(a Atom, aesthetic bool, cands []Candidate, cfg vault.PlaceConfig) []Neighbour  // search.Build over cands' Text; near = top cfg.Near by cosine; plus the far neighbour (other class) flagged Far; excerpts = CapExcerpt(Evidence, cfg.ExcerptChars)
func Decide(a Atom, aesthetic bool, v Verdict, nbs []Neighbour, cfg vault.PlaceConfig) Decision   // pure
func Place(ctx context.Context, p provider.Provider, pr provider.Prompt, a Atom, it Item, nbs []Neighbour, cfg vault.PlaceConfig) (Decision, provider.Usage, error)
```
`Decide` (code decides; the verdict is only advice):
- Unknown verdict → `new`. For `duplicate`, `extends`, `contradicts`: the target must be the id of one of `nbs`; otherwise → `new` (model output is never trusted as an id or path). `cos` = that neighbour's `Cosine`.
- `duplicate`: if `a.Stance == "reads"` → `rereads` target when `cos >= cfg.DuplicateCosine`, else `extends`; other stances → `duplicate` when `cos >= cfg.DuplicateCosine`, else `extends`.
- `contradicts`: `contradicts` when the atom and the target share a tag or `cos >= cfg.ContradictCosine`, else `extends`.
- `extends` → `extends` target.
- `new` → `new` (a `new` decision always has an empty `Target`); additionally, if `aesthetic` and the best near (non-far) cosine is in `[cfg.EchoLow, cfg.EchoHigh)`, set `Echo` true and `EchoOf` = that neighbour's id.
`Place`:
- No neighbours → `Decision{Action: "new"}` without a call.
- Otherwise exactly one call per atom (never batched): `Request{Role: "place", System: pr.Text, User: ...}` where the user message contains the new atom (claim and evidence, fenced with `intake.Fence` and `it.Delim`) and the list of neighbours as `id`, cosine (2 decimals), `far` flag and the capped excerpt, also fenced. Nothing else from the vault is sent (no `inbox/` text other than the current intake). `CallJSON` into `Verdict`, validated (`verdict` in the four values). Then `Decide`. Errors → PROVIDER_ERROR (the caller drops the atom and reports it).

Tests: `TestPlaceDuplicateLowCosine` (duplicate at 0.5 → extends), `TestPlaceDuplicateHigh` (0.9 → duplicate), `TestPlaceReads` (reads atom, duplicate at 0.95 → rereads), `TestPlaceEcho` (aesthetic new with best cosine 0.4 → echo), `TestPlaceContradictNoTag` (contradicts at 0.1 without shared tag → extends), `TestPlaceContradictSharedTag` (0.1 with shared tag → contradicts), `TestPlaceBadTarget` (target `../../etc/passwd` or an unknown id → new), `TestPlaceExcerptCap` (500-char evidence → 300 in the request), `TestPlaceOneCallPerAtom`, `TestPlaceNoNeighbours` (no call).
