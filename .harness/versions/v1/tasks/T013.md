# T013: Full init command and shared CLI vault helpers

Phase 3 · Model: sonnet: wires existing vault, txn, gitops and prompt APIs into one command · Depends-on: T003, T010, T012 · Covers: R1, R20 (prompts written, versions in state), R21 (init commit), R24 (guard on init)

## Brief
Complete `init` in `internal/cli/cmd_init.go` and add shared helpers in `internal/cli/vaultctx.go`. Existing APIs to use: `vault.Open/GuardPath/LoadConfig/MarshalConfig/DefaultConfig`, `(*Vault).Begin` with `vault.TxnOptions`, `(*Txn).WriteFile/Commit`, `(*Vault).LoadState/SaveState`, `gitops.Available/IsRepo/Init/New`, `provider.DefaultPrompts/LoadPrompts/Versions`, `errs`.

Helpers (`vaultctx.go`, used by every later command):
```go
func (e *Env) openVault() (*vault.Vault, vault.Config, error)            // VaultRoot -> vault.Open -> LoadConfig
func (e *Env) begin(v *vault.Vault, cfg vault.Config, command string) (*vault.Txn, error)
func (e *Env) today() string                                             // e.Now().Format("2006-01-02")
```
`begin`: `DryRun` from `--dry-run`; commit disabled when `--no-commit`, `cfg.Git.Commit == false`, or git is unavailable (then `Committer` nil); otherwise `Committer: gitops.New(v.Root)`; `PromptVersions` from `provider.LoadPrompts(v.Root)` (`provider.Versions`); `Now: e.Now`.

`init <dir>`:
1. `vault.GuardPath(dir)`; create `<dir>` and folders `notes hunches sources topics proposals inbox archive .slowhunch .slowhunch/prompts`.
2. Open the vault, `begin(... "init")`, then write only files that do not exist yet: `.slowhunch/config.json` (`MarshalConfig(DefaultConfig())`), `.slowhunch/prompts/{gate,extract,place}.md` (embedded defaults), `.gitignore` with the lines `.slowhunch/cache/`, `.slowhunch/audit.log`, `.slowhunch/state.json`, `.slowhunch/reports/`, and `AGENTS.md` and `CLAUDE.md` with byte-identical short text (title `# Agent instructions for this slowhunch vault`, then three rules: run `slowhunch skill` at session start; run `slowhunch verify` before and after any batch; write only through the `slowhunch` CLI, never edit files directly).
3. An existing `AGENTS.md` or `CLAUDE.md` is never touched: add a warning `{"code": "EXISTS", "path": "AGENTS.md", "message": "left unchanged"}`. Other existing files are kept silently.
4. Git: if `gitops.Available()` is false, add warning `{"code": "GIT_MISSING", ...}` and do not commit (init still succeeds, exit 0). Else, if `<dir>` is not inside a repo, `gitops.Init(dir)`; commit the written files with the txn (`ids` = `[<dir base name>]`, counts `files: N`). Also save `State.PromptVersions`.
5. Result: `{"vault": "<abs>", "created": [sorted rel paths written], "warnings": [...], "git": {"commit": "<hash or empty>"}}`; `warnings` is `[]` when empty.

Tests (`internal/cli/cmd_init_test.go`, temp dirs; call `Run` in-process): `TestInitCreates` (all folders, config, three prompts, identical AGENTS.md/CLAUDE.md, `.gitignore` lines, exactly one commit containing those files), `TestInitTwice` (second init: warnings EXISTS for both agent files, both byte-identical, exit 0, no new commit), `TestInitKeepsForeignAgentsFile` (a pre-existing custom AGENTS.md stays byte-identical), `TestInitGitMissing` (`t.Setenv("PATH", "")` → exit 0, warning GIT_MISSING, no `.git`), `TestInitProtected` (`SLOWHUNCH_TEST=1`, `SLOWHUNCH_PROTECTED` = parent temp dir → BAD_INPUT exit 2, nothing created).
