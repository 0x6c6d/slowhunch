# T006: Id generation, slugs and collision suffixes

Phase 2 · Model: opus: slugs become file names, so sanitization is a path-safety Risk item · Depends-on: T001 · Covers: R4

## Brief
Create `internal/vault/ids.go` (package `vault`; the package may already contain `config.go`) + `ids_test.go`. Pure functions, no I/O.

API (exact):
```go
func Slug(s string, max int) string
func ShortHash(normalizedText string) string                 // first 4 hex chars of sha256(normalizedText)
func SourceID(medium, author, title, normalizedText string) string
func AtomID(stance, sourceID, locator, claim string) string
func KebabID(text string) string                             // hunch and proposal ids: Slug(text, 60)
func UniqueID(id string, exists func(string) bool) string    // id, else id-2, id-3, ...
```
Rules:
- `Slug`: lowercase; fold common Latin accents to ASCII (á→a, é→e, ö→o, ü→u, ñ→n, ç→c, ß→ss, ø→o, å→a, æ→ae; others may be dropped); every run of characters outside `[a-z0-9]` becomes one `-`; trim `-` at both ends; cut to at most `max` characters, then trim a trailing `-`. The result only ever contains `[a-z0-9-]` (never `.`, `/`, `\`, NUL or an empty path element); it may be `""`.
- `SourceID`: `<medium>-<author>-<title>-<short>` with each part `Slug(part, 24)`; author part is the slug of the **last word** of the author (`"Philip Larkin"` → `larkin`); empty author → `anonymous`; empty title slug → `untitled`; `own` sources are `own-<title>-<short>` (no author). `<short>` = `ShortHash(normalizedText)`.
- `AtomID`: `<stance>-<base>-<loc>` where `<base>` is the source id without its leading `<medium>-` and trailing `-<short>` (`poem-larkin-trees-ab12` → `larkin-trees`; `own-notes-ab12` → `notes`), `<loc>` = `Slug(locator, 24)` (`lines 1-2` → `lines-1-2`, `timecode 1:23-1:31` → `timecode-1-23-1-31`); empty locator → `Slug(claim, 24)`, and `untitled` if that is empty too. Empty sourceID → `<stance>-<loc>`.
- Example that must hold: `SourceID("poem", "Philip Larkin", "Trees", t)` == `"poem-larkin-trees-" + ShortHash(t)` and `AtomID("crafts", "poem-larkin-trees-ab12", "lines 1-2", "")` == `"crafts-larkin-trees-lines-1-2"`.
- `KebabID("What makes a line stick?")` == `what-makes-a-line-stick`; at most 60 characters; empty → `untitled`.
- `UniqueID`: returns `id` if `!exists(id)`, else the first of `id-2`, `id-3`, ... that does not exist.
- Ids never depend on the claim wording once created (callers store them); nothing here reads files.

Tests: `TestIDExamples` (both examples above, own, anonymous, 24-character cuts, accent folding), `TestUniqueID` (`-2`, `-3`), `TestSlugSafety` (inputs such as `../../etc/passwd`, `/abs/path`, `a\x00b`, `C:\\x`, `..`, emoji-only, 500 characters → only `[a-z0-9-]`, no leading or trailing `-`, within `max`).
