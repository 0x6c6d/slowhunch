# T042: Policy tests: no push/pull/force, single network and exec sites, test guard

Phase 7 · Model: haiku: source-scanning tests with fixed rules · Depends-on: T008, T039 · Covers: R21 (never push/pull/force), R22 (single egress), R24, Deliverables (stdlib only)

## Brief
Create a test-only package `internal/policy` with `doc.go` (`// Package policy holds repository-wide policy tests.` + `package policy`) and `policy_test.go`. The tests walk the repository's Go files (find the module root by walking up from the test's working directory to the directory containing `go.mod`; skip `.git`, `.harness`, `.claude`, `bin`).

- `TestNoForbiddenGit`: no non-test `.go` file contains a match of the regular expression `git (push|pull)|--force`, nor the Go string literals `"push"`, `"pull"`, `"--force"` (report file and line on failure).
- `TestNetworkOnlyOpenAI`: among non-test `.go` files, only files under `internal/provider/openai/` import `"net/http"` (parse imports with `go/parser` in `ImportsOnly` mode).
- `TestExecOnlyGitopsAndExecProvider`: only files under `internal/gitops/` and `internal/provider/exec/` import `"os/exec"`.
- `TestStdlibOnly`: `go.mod` has no `require` directive, `go.sum` does not exist, and no import path outside the standard library and `github.com/0x6c6d/slowhunch/` appears in any `.go` file (standard library = first path element has no dot).
- `TestTestGuard`: with `t.Setenv("SLOWHUNCH_TEST", "1")` and `t.Setenv("SLOWHUNCH_PROTECTED", <temp dir A>)`, `vault.GuardPath` refuses `A` and `A/sub/v` and allows a sibling temp dir `B`; `vault.Open` on a vault inside `A` fails.

Do not modify any other file. The test file itself may contain the forbidden strings (it is a `_test.go` file).
