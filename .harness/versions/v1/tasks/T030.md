# T030: Intake reading, input checks, medium inference

Phase 5 · Model: sonnet: input validation with a fixed error table · Depends-on: T007 · Covers: R7

## Brief
Create package `intake` (`internal/intake/read.go` + `read_test.go`). Use `errs` and `vault.Mediums` / `vault.IsAesthetic`.

API (exact):
```go
type Input struct { Text string; Path string; Ext string }   // Path/Ext empty for argument or stdin text
const MaxChars = 12000
const ArtHint = "describe or quote the image or scene; there is no vision or audio model"
func Read(arg string, stdin io.Reader) (Input, error)
func Check(in Input, medium, title, author string) error
func InferMedium(in Input) string
```
`Read`:
- `"-"` → read stdin (read at most 4*MaxChars+4 bytes; more → TOO_LONG).
- An existing path: a directory → BAD_INPUT; a regular file with extension (lowercased) `.txt` or `.md` → read it (same size limit); any other extension, including `.pdf` → UNSUPPORTED ("only .txt and .md files are read").
- A non-existing argument without whitespace that ends in a file-like extension of a binary or document format (`.pdf .doc .docx .epub .png .jpg .jpeg .gif .mp3 .mp4 .wav .mov`) → UNSUPPORTED.
- Otherwise the argument itself is the text.
- Text must be valid UTF-8 (else BAD_INPUT). slowhunch never fetches URLs: an argument that is just a URL is treated as text (the gate will judge it).

`Check` (in this order): medium not in `vault.Mediums` → BAD_INPUT; medium `art` or `film` with empty/whitespace text → UNSUPPORTED with hint `ArtHint`; empty/whitespace text → BAD_INPUT; more than `MaxChars` Unicode characters → TOO_LONG (no truncation); medium `poem`, `lyric` or `film` without title → BAD_INPUT; `quote` without author → BAD_INPUT.

`InferMedium` (only used when `--as` is absent; extension and length only): more than 1,000 characters → `article`; otherwise `other` (this covers short text with line breaks and short single lines).

Tests: `TestIntakeRead` (argument text, stdin via `-`, `.txt` and `.md` files, `.pdf` file and missing `.pdf` → UNSUPPORTED, directory → BAD_INPUT, invalid UTF-8), `TestIntakeCheck` (table: exactly 12,000 characters OK incl. multi-byte runes, 12,001 → TOO_LONG, empty → BAD_INPUT, `film` with text but no title → BAD_INPUT, `art` with no text → UNSUPPORTED with `ArtHint`, `quote` without author → BAD_INPUT, unknown medium → BAD_INPUT), `TestInferMedium`.
