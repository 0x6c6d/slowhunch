# T003: Vault config defaults and minimal init

Phase 1 · Model: sonnet: config schema plus first real command · Depends-on: T002 · Covers: R1 (partial), R18 (config schema), R23 (cap defaults)

## Brief
Create the config type in package `vault` and a minimal `init` command (a later task completes `init`).

`internal/vault/config.go` (package `vault`) + `config_test.go`:
```go
type ProviderConfig struct {
    Name      string   `json:"name"`
    BaseURL   string   `json:"base_url,omitempty"`
    Model     string   `json:"model,omitempty"`
    APIKeyEnv string   `json:"api_key_env,omitempty"`
    Command   []string `json:"command,omitempty"`
}
type CapsConfig struct {
    AtomsPerAssertsInput   int `json:"atoms_per_asserts_input"`
    AtomsPerAestheticInput int `json:"atoms_per_aesthetic_input"`
    CharsPerCall           int `json:"chars_per_call"`
}
type PlaceConfig struct {
    Near             int     `json:"near"`
    DuplicateCosine  float64 `json:"duplicate_cosine"`
    ContradictCosine float64 `json:"contradict_cosine"`
    EchoLow          float64 `json:"echo_low"`
    EchoHigh         float64 `json:"echo_high"`
    ExcerptChars     int     `json:"excerpt_chars"`
}
type GitConfig struct { Commit bool `json:"commit"` }
type Config struct {
    Provider   ProviderConfig            `json:"provider"`
    Roles      map[string]ProviderConfig `json:"roles,omitempty"`
    Caps       CapsConfig                `json:"caps"`
    Place      PlaceConfig               `json:"place"`
    SendPolicy string                    `json:"send_policy"`
    Git        GitConfig                 `json:"git"`
}
func DefaultConfig() Config
func ConfigPath(root string) string                // <root>/.slowhunch/config.json
func LoadConfig(root string) (Config, error)
func MarshalConfig(c Config) []byte                 // 2-space indented JSON + trailing newline
```
- Defaults: provider `{name: "openai-compatible", base_url: "http://localhost:11434/v1", model: "llama3.1", api_key_env: "SLOWHUNCH_API_KEY"}`; caps `5 / 3 / 12000`; place `near 5, duplicate_cosine 0.80, contradict_cosine 0.20, echo_low 0.20, echo_high 0.80, excerpt_chars 300`; `send_policy "excerpt_only"`; `git.commit true`.
- `LoadConfig` starts from `DefaultConfig()` and unmarshals the file over it (missing fields keep defaults). Missing file or invalid JSON → `errs.Fatal(errs.BadInput, ...)` (exit 1). `send_policy` other than `excerpt_only` → `errs.Fatal(errs.Unsupported, ...)`.

`internal/cli/cmd_init.go`: `init <dir>` (minimal): create `<dir>` and the folders `notes hunches sources topics proposals inbox archive .slowhunch`; write `.slowhunch/config.json` with `MarshalConfig(DefaultConfig())` only if it does not exist. Result: `{"vault": "<abs dir>", "created": [<relative paths created, sorted>]}`. Missing `<dir>` argument → BAD_INPUT exit 2.

Tests: `TestConfigDefaults`, `TestConfigPartialFile` (a file with only `{"git":{"commit":false}}` keeps other defaults), `TestConfigInvalid` (bad JSON → exit-1 error), `TestInitMinimal` in `internal/cli` (folders and config exist; JSON has `"schema": 1`).
