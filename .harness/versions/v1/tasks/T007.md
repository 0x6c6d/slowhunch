# T007: Type schema, field validation, locator grammar, links, inbox format

Phase 2 · Model: sonnet: table-driven validation on top of the parser · Depends-on: T005 · Covers: R2, R3, R6, R8 (inbox format)

## Brief
Add to package `vault` (`internal/vault/schema.go`, `locator.go`, `links.go`, `inbox.go` + tests). Uses `internal/frontmatter` (`Doc`, `GetString`, `GetList`, `GetMaps`) and `internal/errs`.

Vocabulary (exported vars/funcs):
- `Types = note source hunch proposal topic`; `func Folder(typ string) string` → `notes sources hunches proposals topics` ("" if unknown).
- `Mediums = paper article blog post thread page code book own poem lyric prose quote film art talk other`; `Stances = asserts crafts reads`; `HunchStates = open warming tested dropped`; note `status` ∈ `active contradiction`; proposal `status` ∈ `open testing done dropped`; hunch evidence `relation` ∈ `supports weakens`.
- `func IsAesthetic(m string) bool` (poem lyric prose quote film art); `func IsFactual(m string) bool` (paper article blog page post thread code talk book); `own` and `other` are neither.

Fields allowed per type (anything else → BAD_INPUT naming the field):
- common: `id type created updated author rev tags bears_on links` (for `source`, `author` is the work's author and the writer field is `added_by` instead).
- note: `claim evidence stance locator source status unlocks repurpose confidence rereads rendering translates corroborations`.
- hunch: `question state next_test evidence revisit`. source: `url medium title author published atoms translates owner_note text_hash added_by`. proposal: `items idea cheapest_test status`. topic: `title`.
- List-valued: `tags bears_on links unlocks rereads atoms items corroborations`; maps: hunch `evidence` (keys `date note relation`; an empty `[]` is valid); all others are scalars (note `evidence` is a scalar string).
- Required: common `id type created updated rev` and (`author`, or `added_by` for source); note `claim evidence stance`; hunch `question state`; source `medium title`; proposal `idea status`; topic `title`.
- Values: dates `YYYY-MM-DD` and valid; `author`/`added_by` is `human` or matches `^agent:[^/\s]+/\S*$`; enums as above; `confidence` a decimal in [0,1] and only when `stance` is `asserts`; `locator` must parse; note `claim` is one line; ids in id-list fields match `^[a-z0-9]+(-[a-z0-9]+)*$`.

API (exact):
```go
func Validate(d *frontmatter.Doc, fileID string) error   // *errs.Error BAD_INPUT; also id == fileID and type known
type Locator struct { Kind string; From, To int; Name string }  // Kind: line lines stanza verse comment section timecode region
func ParseLocator(s string) (Locator, error)
func (l Locator) LineRange() (from, to int, ok bool)            // ok only for line/lines
func Links(d *frontmatter.Doc) []string   // ids from [[id]] in the body plus fields source, bears_on, links, unlocks, rereads, translates, atoms, items and hunch evidence[].note; deduplicated, first-seen order
func NoteBody(claim, evidence string) string   // claim + "\n\n" + each evidence line prefixed "> " (empty line -> ">") + "\n"
func NumberedMedium(m string) bool             // poem lyric prose quote film code
func FormatInbox(normalized, medium string) []byte   // numbered media: "N\t<line>\n" for every line (N from 1); else normalized + "\n"
func InboxLines(stored []byte, medium string) []string  // content lines without the "N\t" prefix
func InboxPlain(stored []byte, medium string) string    // strings.Join(InboxLines(...), "\n")
```
Locator grammar, closed set (anything else is an error): `line N`, `lines N-M` (1 ≤ N ≤ M), `stanza N`, `verse N`, `comment N`, `section <name>` (1–80 chars, one line), `timecode M:SS-M:SS` (start < end, seconds 00–59), `region x1,y1,x2,y2` (x1 < x2, y1 < y2). N ≥ 1.

Tests: `TestValidateTypes` (a valid doc of each type passes; one failing doc per rule: unknown field, missing required, bad enum, bad date, confidence on crafts, id mismatch), `TestLocatorGrammar` (each shape valid and invalid forms such as `lines 3-1`, `line 0`, `page 4`, `timecode 1:61-2:00`), `TestLinks`, `TestNoteBody` (evidence round-trips by stripping `> `), `TestInboxFormat` (numbered and plain round trips).
