# T018: link, unlink, backlinks, graph commands

Phase 3 · Model: sonnet: small graph commands on existing index and txn · Depends-on: T011, T013, T014 · Covers: R6 (one-direction links, computed backlinks), R14 (link, unlink, backlinks, graph)

## Brief
Add `internal/cli/cmd_link.go` (link, unlink), `internal/cli/cmd_graph.go` (backlinks, graph) + tests. Use `env.openVault/begin/today`, `(*Vault).LoadIndex`, `(*Index).Get/Backlinks/Neighbourhood`, `(*Txn).PutDoc/Commit`, `frontmatter.Rev`, `vault.Validate`.

- `link <from> <to>`: both ids must exist (NOT_FOUND). If `<to>` is a hunch or proposal, add it to `<from>`'s `bears_on`; otherwise add it to `<from>`'s `links` list. Links are one direction only: never modify `<to>`. Already present → success with `"changed": false`, no write, no commit. Otherwise set `updated` = today, validate, `PutDoc` with the current rev (read just before), commit (`ids [from]`, counts `linked: 1`). `<from> == <to>` → BAD_INPUT. Result `{"from", "to", "field", "changed", "git": {"commit"}}`.
- `unlink <from> <to>`: removes `<to>` from `bears_on` and `links` of `<from>` (`<to>` need not exist any more). Not present → `"changed": false`, no commit. Otherwise write and commit (counts `unlinked: 1`).
- `backlinks <id>`: computed from the index (any `[[id]]` in bodies and the id fields listed by `vault.Links`). Unknown id → NOT_FOUND. Result `{"id", "backlinks": [sorted ids]}`.
- `graph <id> [--depth N]`: default depth 1, allowed 1–5 (else BAD_INPUT). Result `{"id", "depth", "nodes": [...], "edges": [{"from", "to"}]}` from `Neighbourhood`.
- `backlinks` and `graph` are read-only (no txn, no audit).

Tests (`internal/cli/cmd_link_test.go`): `TestCRUDLink` (note → topic goes to `links`, note → hunch goes to `bears_on`, the target file is byte-identical, one commit each), `TestCRUDLinkIdempotent` (second identical link: no commit), `TestCRUDUnlink`, `TestCRUDBacklinks`, `TestCRUDGraphDepth` (chain a→b→c: depth 1 from a has a,b; depth 2 has a,b,c; depth 9 → exit 2), `TestCRUDLinkMissing` (unknown target → NOT_FOUND, nothing written).
