API (exact):
```go
type Atom struct {
    Claim      string   `json:"claim"`
    Evidence   string   `json:"evidence"`
    Stance     string   `json:"stance"`
    Locator    string   `json:"locator"`
    Tags       []string `json:"tags"`
    Confidence *float64 `json:"confidence,omitempty"`
    Rendering  string   `json:"rendering,omitempty"`
}
type Drop struct { Index int; Code, Reason string }   // Index = position in the model's list
func CheckAtoms(raw []Atom, it Item, caps vault.CapsConfig) ([]Atom, []Drop)
func Extract(ctx context.Context, p provider.Provider, pr provider.Prompt, it Item, caps vault.CapsConfig) ([]Atom, []Drop, provider.Usage, error)
```
`CheckAtoms` (pure; rules enforced in code, never trusted to the prompt), per atom in order, first failing rule drops it:
1. `BAD_STANCE`: stance not in asserts, crafts, reads.
2. `BAD_CLAIM`: claim empty or containing a newline.
3. `EVIDENCE_NOT_FOUND`: evidence empty or not an exact substring of `it.Plain`.
4. `LOCATOR_REQUIRED`: locator empty while the medium is aesthetic, `thread` or `code`.
5. `BAD_LOCATOR`: locator does not parse; `thread` needs kind `comment`; `code` needs kind `lines`; a `line`/`lines` range outside `1..len(InboxLines)`, or the joined lines of that range do not contain the evidence.
6. `CONFIDENCE_NOT_ASSERTS`: confidence set on a non-asserts atom. `BAD_CONFIDENCE`: outside [0,1].
Then: medium `own` + stance asserts + no confidence → confidence 0.3; tags → `vault.Slug(tag, 32)`, empty ones removed, deduplicated. Caps: aesthetic media keep at most `caps.AtomsPerAestheticInput`, all others `caps.AtomsPerAssertsInput`; excess atoms (in order) are dropped with code `CAP` (reported, never silent).

`Extract`:
- If the number of characters of `it.Plain` exceeds `caps.CharsPerCall` → `errs.New(errs.TooLong, "input exceeds chars_per_call cap", ...)`, no call (the cap is reported, never truncated).
- One call: `Request{Role: "extract", Medium, System: pr.Text, User: Header(it) + "\nClass: <class>. Return 1 to <cap> atoms. Copy evidence exactly, without the line-number prefixes.\n\n" + FencedText(it), MaxTokens: 2000}` with `CallJSON` into `struct{ Atoms []Atom }`, validate: at least one atom (else repair).
- Return `CheckAtoms` of the reply. A provider error → PROVIDER_ERROR (caller counts the item as an error).

Tests (fake provider and hand-built Items using `vault.FormatInbox`): `TestExtractEvidenceDrop` (paraphrased evidence → EVIDENCE_NOT_FOUND), `TestExtractBadLocator` (`lines 5-6` on a 2-line poem, and a range not containing the evidence → BAD_LOCATOR; missing locator on a poem → LOCATOR_REQUIRED), `TestExtractConfidenceCrafts` (CONFIDENCE_NOT_ASSERTS), `TestExtractCaps` (poem with 5 valid atoms → 3 kept, 2 CAP drops; article 7 → 5 kept), `TestExtractOwnDefaults`, `TestExtractCode` (`lines 2-3` required and valid), `TestExtractCharsCap` (no call), `TestExtractPrompt` (user message contains the fenced text).
