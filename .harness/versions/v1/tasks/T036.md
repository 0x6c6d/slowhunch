## Brief
Add `internal/pipeline/add.go` (+ small helpers in `internal/pipeline/write.go`) and `add_test.go`. Use: `intake.Read/Check/InferMedium/Normalize/TextHash/NewDelimiter/ContainsSecret`, `vault.SourceID/AtomID/UniqueID/FormatInbox/InboxPlain/NoteBody/Validate/IsAesthetic`, `(*Vault).LoadIndex/Begin`, `(*Txn).Touch/WriteFile/PutDoc/Commit`, `Gate`, `Extract`, `BuildNeighbours`, `Place`, `report.New/Link/AddCost/Save`, `provider.Versions`.

API (exact):
```go
type Deps struct {
    Vault     *vault.Vault
    Config    vault.Config
    Providers map[string]provider.Provider   // keys gate, extract, place
    Prompts   map[string]provider.Prompt
    Committer vault.Committer                // nil = no git
    Now       func() time.Time
    Author    string                         // "agent:<provider>/<model>" for written atoms and added_by
}
type Options struct {
    Arg string; Stdin io.Reader
    Medium, URL, Title, Author, Note, Hunch string
    Force, DryRun, NoCommit bool
}
func Add(ctx context.Context, d Deps, o Options) (*report.Report, error)
```
Flow (input errors return an error and touch nothing):
1. `intake.Read`; medium = `o.Medium` or `InferMedium` (set `Report.Medium`, `MediumInferred`); `intake.Check`; `Normalize`; `text_hash`; source id = `SourceID(medium, author, title, normalized)`; empty author is written as `anonymous`, never guessed. `--hunch` id must exist as a hunch (NOT_FOUND).
2. `ContainsSecret(normalized)` → BAD_INPUT; nothing sent, nothing written.
3. Idempotency: a source in the index with the same `text_hash` → return a report with `Source = Link(existing id)`, `counts.existing = 1`; write nothing at all (no file, no report file, no audit line, no commit).
4. Build the `Item` (Stored = `FormatInbox(normalized, medium)`, Plain, Delim, Force). `Gate`: rejected or error → counts `rejected = 1`, the error in `Errors` (`item` = source id), write nothing, return the report (no error).
5. `Extract`; each `Drop` → `Errors` entry (`item` = `atom <index>`, code, reason); an extract error → `Errors` and write nothing.
6. For each kept atom in order: candidates = existing notes (text = claim + evidence + tags) plus atoms already decided in this run; `BuildNeighbours`; `Place`; a place error drops that atom into `Errors`. Atom id = `UniqueID(AtomID(stance, sourceID, locator, claim))` against the index and ids taken in this run.
7. Writes (in this task: actions `new`, `extends`, `rereads`; until the outcomes task lands, treat `duplicate` and `contradicts` like `extends`): first `txn.Touch` every path this run will write, then write `inbox/<sid>.txt`, `sources/<sid>.md` (fields `id type=source created updated added_by rev tags bears_on url medium title author published owner_note text_hash atoms`), and `notes/<id>.md` (fields `id type=note created updated author rev tags bears_on claim evidence stance locator source status=active` plus `confidence`, `rendering`, `links: [target]` for extends, `rereads: [target]` for rereads; body `NoteBody`). `bears_on` includes `--hunch` when given. Validate each doc before writing.
8. `Report.Atoms` gets `AtomRef{ID: Link(id), Claim, Stance, Locator, Action, Target: Link(target) or ""}`; counts `atoms`, `dropped`, `errors`; `Cost` per role from usages.
9. Commit via the txn (`ids` = source id + atom ids, counts `atoms: N`); `Report.Git` = `{commit}` or `{"", skipped: "dry-run" | "no-commit" | "no-git"}`. Then, unless dry-run, `report.Save`. Before returning, assert every id in `Report.IDs()` exists on disk (dry-run: in the plan); otherwise return an error.
- Dry-run: providers are still called, but the vault stays byte-identical (no inbox, no report file, no state, no audit, no commit).

Tests (`internal/pipeline/add_test.go`, temp vault from `vault.Open` on a dir with `.slowhunch/` + `gitops.Init`, fake providers): `TestAddInputErrors` (`.pdf` file → UNSUPPORTED, 12,001 chars → TOO_LONG, empty → BAD_INPUT, `--as film` without title → BAD_INPUT, `--as art` without text → UNSUPPORTED with the art hint; each writes nothing), `TestAddBasic` (article: source, inbox copy, atoms, one commit, report saved), `TestAddIdempotent` (second identical add: tree hash unchanged, no new commit, `existing` 1), `TestAddDryRun` (tree hash including `.slowhunch` unchanged, no commit), `TestFencing` (every recorded request contains the run delimiter lines and the delimiter does not occur in the input), `TestSecret` (input with `sk-` + 20 chars → BAD_INPUT, zero provider calls, nothing written).
