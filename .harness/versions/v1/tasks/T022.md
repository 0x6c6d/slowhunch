# T022: search command: ranking, filters, budget, partners

Phase 4 · Model: sonnet: ranking and filtering on existing index and TF-IDF code · Depends-on: T021, T011, T013 · Covers: R15

## Brief
Add `internal/search/rank.go` (ranking, pure) and `internal/cli/cmd_search.go` + tests. Use `search.Build/Similar/Query/Cosine`, `env.openVault()`, `(*Vault).LoadIndex`, `(*Index).OfType/Get/MediumOf/Neighbourhood`.

`search "<query>" [--medium M] [--stance S] [--tag X] [--hunch ID] [--budget TOKENS] [--limit N]` (one call, read-only, no audit):
- Corpus: every note; document text = claim + " " + evidence + " " + tags joined by spaces.
- Filters (AND): `--medium` (note's source medium via `MediumOf`), `--stance`, `--tag`, `--hunch` (only notes within 2 link hops of the hunch in the undirected link graph: hops 0 = the hunch id is in the note's `bears_on`; unknown hunch → NOT_FOUND). Invalid medium/stance → BAD_INPUT.
- Score = cosine × (1 + 0.1 × recency) / (1 + hops), recency = 1 / (1 + days_since_created/365) using the note's `created` date and today (`env.Now`); hops = 0 when `--hunch` is not given. Only cosine > 0 hits. Sort by score desc, then id asc.
- `--limit` default 10. `--budget` (0 = unlimited): tokens per hit = ceil((len(quote)+len(locator)+len(source))/4) in bytes; include hits in rank order while the running total stays ≤ budget; stop at the first hit that would exceed it.
- Each hit: `{"id", "score" (rounded to 4 decimals), "claim", "quote" (the evidence), "locator", "source", "source_title", "medium", "stance"}` plus:
  - `"rereads": {"id", "quote", "locator"}` when the note is a `reads` atom with a `rereads` entry (first existing target);
  - `"counterpart": {"id", "title"}` when the note's source has `translates` pointing at an existing source.
- Result: `{"query", "hits": [...], "count", "tokens"}`. Text mode: `id  score  claim` plus the quote indented.

`rank.go` exports the pure parts so they can be unit-tested without files, e.g. `func Score(cosine float64, daysOld int, hops int) float64` and `func Budget(hits []Ranked, budget int) ([]Ranked, int)` (your own `Ranked` struct).

Tests: `TestSearchScore` (formula), `TestSearchBudget`, and in `internal/cli/cmd_search_test.go` `TestSearchSeeded`: seed a temp vault with 20 notes (write files with the vault API: sources with different media, mix of stances) so that a known query ranks the expected atom first; `--medium poem` returns only poem-source atoms; `--stance reads` only reads atoms; a small `--budget` returns fewer hits than unlimited; a `reads` hit carries its `rereads` partner; a hit whose source translates another source carries `counterpart`.
