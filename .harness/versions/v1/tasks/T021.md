# T021: TF-IDF index, cosine, neighbour selection

Phase 4 · Model: sonnet: self-contained stdlib algorithm with clear tests · Depends-on: T001 · Covers: R11 (neighbour selection), R15 (TF-IDF basis)

## Brief
Create `internal/search` (package `search`, files `tfidf.go`, `neighbours.go` + tests). Pure in-memory, stdlib only, no file access.

API (exact):
```go
type Doc struct { ID, Text string }
type Vector map[string]float64            // L2-normalized
type Hit struct { ID string; Score float64 }
type Index struct { /* unexported */ }
func Tokenize(s string) []string           // lowercase; split on anything that is not a Unicode letter or digit; drop tokens of length 1 and a small English stopword list (the, a, an, and, or, of, to, in, is, it, that, this, for, on, with, as, are, be, by, at, from)
func Build(docs []Doc) *Index
func (ix *Index) Len() int
func (ix *Index) Query(text string) Vector         // TF-IDF vector of arbitrary text under this index's IDF
func (ix *Index) DocVector(id string) Vector       // nil if unknown
func Cosine(a, b Vector) float64                  // 0 for empty vectors
func (ix *Index) Similar(text string, limit int, keep func(id string) bool) []Hit   // score > 0 only; sorted by score desc, then id asc; keep==nil keeps all; limit<=0 = no limit
func Neighbours(ix *Index, text string, near int, aesthetic func(id string) bool, newIsAesthetic bool) (nearHits []Hit, far *Hit)
```
Rules:
- TF = count / tokens in doc; IDF = ln((1+N)/(1+df)) + 1; vectors L2-normalized, so identical texts score 1.0 (within 1e-9) and texts with no shared token score 0.
- `Neighbours`: `nearHits` = top `near` hits of `Similar(text, near, nil)`; `far` = the highest-cosine document (score may be 0) whose class differs (`aesthetic(id) != newIsAesthetic`) and that is not in `nearHits`; ties by id; nil if there is no such document.
- Performance: `Build` over 2,000 docs of ~60 words plus one `Similar` call must finish in well under one second (add `BenchmarkBuild2000`, not run by default).

Tests (`internal/search/tfidf_test.go`): `TestSearchTokenize`, `TestSearchCosine` (identical ≈ 1, disjoint = 0, partial between), `TestSearchSimilarOrder` (deterministic ordering, `keep` filter, limit), `TestSearchNeighbours` (near count; far comes from the other class and is not in near; nil when the other class is empty).
