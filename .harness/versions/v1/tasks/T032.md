# T032: Prompt fencing, look-alike neutralization, secret detector

Phase 5 · Model: opus: prompt-injection fencing and secret blocking are security Risk items (Consequential assumption 4) · Depends-on: T001 · Covers: R22

## Brief
Add `internal/intake/fence.go` and `internal/intake/secret.go` + tests (package `intake`). Every provider prompt built later wraps intake text with these functions; every item is checked with `ContainsSecret` before anything is sent.

API (exact):
```go
func NewDelimiter(text string) (string, error)  // "SLOWHUNCH-INTAKE-" + 16 lowercase hex chars from crypto/rand; regenerate until it does not occur in text (case-insensitive)
func Neutralize(text string) string             // see below
func Fence(text, delim string) string           // "<<<" + delim + ">>>\n" + Neutralize(text) + "\n<<<END " + delim + ">>>"
func ContainsSecret(text string) bool
func Redact(s string, secrets ...string) string // every non-empty secret value replaced by "***"
```
`Neutralize` makes it impossible for the text to open or close a fence: replace every `<<<` with `< < <` and every `>>>` with `> > >` (repeat until none remain), and replace every case-insensitive occurrence of `SLOWHUNCH-INTAKE` with `SLOWHUNCH_INTAKE`. It changes nothing else. Consequence that tests must prove: in `Fence(text, d)` the exact opening line and the exact closing line each occur exactly once, whatever `text` contains (including a copy of the real delimiter lines).

`ContainsSecret` returns true if the text matches any of: `sk-[A-Za-z0-9_-]{16,}`, `AKIA[0-9A-Z]{16}`, `-----BEGIN [A-Z ]*PRIVATE KEY-----`, `ghp_[A-Za-z0-9]{36}`, `xox[bp]-[A-Za-z0-9-]{10,}`. Plain prose such as "the sk- prefix" or "skip-to-content" must not match.

Tests: `TestFencingDelimiter` (prefix and 16 hex; differs between calls; never occurs in a text that already contains `SLOWHUNCH-INTAKE-` strings), `TestFencingLookAlike` (a text containing `<<<END SLOWHUNCH-INTAKE-0123456789abcdef>>>`, `<<<<` and `>>>>>`: the fenced output contains exactly one opening and one closing delimiter line, and the inner text contains no `<<<` or `>>>`), `TestFencingPlainUnchanged` (ordinary prose and a poem pass through byte-identical), `TestSecretPatterns` (one positive per pattern, several negatives), `TestRedact`.

## Verification
`.harness/verify/v1/T032.sh` exits 0. It runs the named tests; negative probes: an injected copy of the closing delimiter must not survive fencing, and secret-like strings must be detected while ordinary prose is not.
