# T025: Run report type, key order, save and load

Phase 4 · Model: sonnet: data type plus JSON persistence · Depends-on: T008 · Covers: R12 (report keys and order, saved report), R23 (cost per role)

## Brief
Create `internal/report/report.go` (package `report`) + tests. Struct field declaration order fixes the JSON key order (encoding/json writes fields in declaration order), so no custom marshaller is needed.

API (exact; JSON tags in parentheses):
```go
type Usage struct { TokensIn int (tokens_in); TokensOut int (tokens_out) }
type AtomRef struct { ID (id); Claim (claim); Stance (stance); Locator (locator); Action (action); Target (target,omitempty) string }
type Contradiction struct { Atom (atom), Contradicts (contradicts) string; Hunches (hunches) []string; Cosine (cosine) float64 }
type HunchMove struct { Hunch (hunch), Note (note), Relation (relation) string }
type Corroboration struct { Atom (atom), Source (source), Date (date) string }
type Echo struct { Atom (atom), Echoes (echoes) string; Cosine (cosine) float64 }
type ItemError struct { Item (item), Code (code), Reason (reason) string }
type GitInfo struct { Commit (commit) string; Skipped (skipped,omitempty) string }
type Report struct {
    RunID          string           `json:"run_id"`
    Source         string           `json:"source"`
    Medium         string           `json:"medium"`
    MediumInferred bool             `json:"medium_inferred"`
    Contradictions []Contradiction  `json:"contradictions"`
    HunchesMoved   []HunchMove      `json:"hunches_moved"`
    Atoms          []AtomRef        `json:"atoms"`
    Corroborations []Corroboration  `json:"corroborations"`
    Echoes         []Echo           `json:"echoes"`
    Wildcards      []any            `json:"wildcards"`
    Collisions     []any            `json:"collisions"`
    Counts         map[string]int   `json:"counts"`
    Errors         []ItemError      `json:"errors"`
    Cost           map[string]Usage `json:"cost"`
    Git            GitInfo          `json:"git"`
}
func New(runID string) *Report                       // every slice and map non-nil (empty JSON arrays/objects, never null)
func Link(id string) string                          // "[[" + id + "]]"
func (r *Report) IDs() []string                      // every id inside [[...]] anywhere in the marshalled JSON, deduplicated, sorted
func (r *Report) AddCost(role string, u Usage)       // sums per role
func (r *Report) Save(v *vault.Vault) error           // .slowhunch/reports/<run-id>.json via v.WriteFile, 2-space indent + newline
func LoadAll(v *vault.Vault) ([]*Report, error)      // every .slowhunch/reports/*.json (sorted by name); missing dir -> empty
```
Conventions for callers (document them in the package comment): ids inside a report are always written as `Link(id)` (e.g. `"atom": "[[crafts-larkin-trees-lines-1-2]]"`), so `IDs()` can check that each exists on disk; `Wildcards` and `Collisions` stay empty in v1. The 11 spec keys appear in exactly this relative order: `contradictions, hunches_moved, atoms, corroborations, echoes, wildcards, collisions, counts, errors, cost, git`.

Tests (`internal/report/report_test.go`): `TestReportKeyOrder` (decode the marshalled JSON with `json.Decoder.Token()` and check the order of the 11 keys; empty report has `[]` not `null`), `TestReportIDs`, `TestReportSaveLoad` (temp vault: save two reports, `LoadAll` returns both with costs), `TestReportAddCost`.
