# T026: stats aggregation and command

Phase 4 · Model: sonnet: counting over existing index and saved reports · Depends-on: T025, T011, T013 · Covers: R16 (stats)

## Brief
Add `internal/report/stats.go` and `internal/cli/cmd_stats.go` + tests. Use `(*Vault).LoadIndex`, `(*Index).OfType/MediumOf`, `report.LoadAll`, `report.Usage`.

```go
type Stats struct {
    AtomsByMedium     map[string]int   `json:"atoms_by_medium"`
    AtomsByStance     map[string]int   `json:"atoms_by_stance"`
    AssertsReadsRatio *float64         `json:"asserts_reads_ratio"`   // asserts / reads, rounded to 4 decimals; null when reads == 0
    HunchesByState    map[string]int   `json:"hunches_by_state"`
    Contradictions    int              `json:"contradictions"`        // notes with status "contradiction"
    Echoes            int              `json:"echoes"`                // sum of len(Echoes) over saved reports
    TokensByRole      map[string]Usage `json:"tokens_by_role"`        // sum of Cost over saved reports
    Atoms             int              `json:"atoms"`
    Hunches           int              `json:"hunches"`
}
func Compute(ix *vault.Index, reports []*Report) Stats   // maps non-nil; notes without a resolvable source medium count under "unknown"
```
Command `stats`: read-only; result = the `Stats` object members at top level (after `schema`, `ok`). Text mode: a short aligned table.

Tests: `internal/report/stats_test.go` `TestStatsCompute` (exact counts by medium and stance, ratio 2/1 → 2, nil when no reads, contradictions, echoes and tokens summed from two reports); `internal/cli/cmd_stats_test.go` `TestStatsCommand` (seeded temp vault: 3 asserts on article sources, 2 crafts and 1 reads on poem sources, one contradiction note, 2 hunches in different states, one saved report with cost and an echo → exact JSON values, `asserts_reads_ratio` 3).
