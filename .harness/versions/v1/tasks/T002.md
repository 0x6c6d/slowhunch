# T002: errs package and CLI core: dispatch, global flags, JSON envelope, exit codes

Phase 1 · Model: sonnet: new multi-file pattern every command builds on · Depends-on: T001 · Covers: R17

## Brief
Create the shared error type and the CLI core. No real commands yet (later tasks register them).

`internal/errs/errs.go` (package `errs`) + `errs_test.go`:
- Constants: `NotFound="NOT_FOUND"`, `BadInput="BAD_INPUT"`, `Unsupported="UNSUPPORTED"`, `TooLong="TOO_LONG"`, `Exists="EXISTS"`, `Conflict="CONFLICT"`, `ConflictRev="CONFLICT_REV"`, `GitMissing="GIT_MISSING"`, `ProviderError="PROVIDER_ERROR"`, `LintFailed="LINT_FAILED"`.
- `type Error struct { Code, Message, Hint string; Exit int; Extra map[string]any }`; `func (e *Error) Error() string` returns `CODE: message`.
- `func New(code, message, hint string) *Error`; `func Fatal(code, message, hint string) *Error` (same, with `Exit: 1`; for config/fatal errors).
- `func CodeOf(err error) string` (via `errors.As`; `""` otherwise).
- `func ExitCode(err error) int`: nil → 0; the `Exit` field if non-zero; CONFLICT, CONFLICT_REV, EXISTS → 4; NOT_FOUND, BAD_INPUT, UNSUPPORTED, TOO_LONG → 2; LINT_FAILED → 3; GIT_MISSING, PROVIDER_ERROR and any non-`*Error` → 1.

`internal/cli` (package `cli`):
- `func Run(args []string, stdin io.Reader, stdout, stderr io.Writer) int`.
- `type Env struct { Stdin io.Reader; Stdout, Stderr io.Writer; JSON, DryRun, NoCommit bool; VaultFlag string; Now func() time.Time }`. `Now` is filled from a package variable `var nowFunc = time.Now` (tests may replace it).
- `type Handler func(env *Env, args []string) (any, error)`; `func register(name, summary string, h Handler)` (call from `init()` in each command file). Names may be two words (`"hunch add"`, `"source facts"`); `Run` tries the two-word name before the one-word name.
- Global flags, accepted anywhere before `--` and removed before the handler sees `args`: `--json`, `--dry-run`, `--no-commit`, `--vault <dir>` and `--vault=<dir>`.
- `func newFlagSet(name string) *flag.FlagSet` (ContinueOnError, output discarded) and `func parseFlags(fs *flag.FlagSet, args []string) ([]string, error)`: flags and positionals may be interleaved (`add text --as poem` works); returns positionals; `--` ends flags.
- `func (e *Env) VaultRoot() (string, error)`: `--vault`, else env `SLOWHUNCH_VAULT`, else the nearest parent of the working directory containing a `.slowhunch/` directory; absolute path; none → `errs.New(errs.NotFound, "no vault found", "run slowhunch init <dir> or pass --vault")`.
- Success output: JSON mode prints one object indented with two spaces: `{"schema": 1, "ok": true, ...}` followed by the members of the handler's result in their own order (marshal the result; if it is a JSON object, splice its members after `"ok": true`; nil → only schema and ok). Text mode: if the result implements `interface{ Text() string }` print that, else print the same JSON.
- Error output: JSON mode prints to stdout `{"schema": 1, "ok": false, "error": {"code": ..., "message": ..., "hint": ...}}` plus the `Extra` members (sorted keys); text mode prints `error: CODE: message` and `hint: ...` to stderr. A non-`*errs.Error` uses code `BAD_INPUT`, hint `internal error`, exit 1. Exit code = `errs.ExitCode(err)`.
- No arguments, unknown command, or flag parse error → `BAD_INPUT`, exit 2 (usage on stderr in text mode). `help` prints the sorted command list with summaries, exit 0.
- `cmd/slowhunch/main.go`: `os.Exit(cli.Run(os.Args[1:], os.Stdin, os.Stdout, os.Stderr))`.

Tests in `internal/cli/cli_test.go` (dummy handlers registered by the test are fine):
`TestSchema` (success and error JSON carry `"schema": 1`; error has code, message, hint; result key order preserved), `TestExitCodes` (unknown command → 2; each code maps per the table; Fatal → 1), `TestGlobalFlags` (global flags before and after the command, `--vault=x` form, interleaved positionals), `TestVaultLookup` (flag beats env beats parent search; none → NOT_FOUND).
