# T004: skill command (guide at most 60 lines)

Phase 1 · Model: haiku: one static text plus a tiny command · Depends-on: T002 · Covers: R16 (skill)

## Brief
Add the `skill` command to `internal/cli` (register it with `register("skill", ..., handler)` in `internal/cli/cmd_skill.go`). It prints a fixed guide for AI agents, stored as a Go string constant `skillText`.

Guide content (plain text, at most 60 lines, at least 20, lines at most 100 characters):
- What slowhunch is: a commonplace book for agents; plain Markdown vault in git; every command has `--json`; slowhunch never fetches from the network: the agent reads links itself and passes text in.
- Data model: atoms (`notes/`, type `note`: one-line `claim` + verbatim `evidence` excerpt, `stance` asserts/crafts/reads, `locator`, `source`), sources (`sources/`, text kept in `inbox/`), hunches (`hunches/`: open questions with dated evidence, states open/warming/tested/dropped), proposals, topics. Links are `[[id]]`, one direction, backlinks computed. Every file has a `rev`; updates need `--rev`.
- Rules: run `slowhunch verify` before and after any batch; write only through the CLI; quote evidence exactly, never paraphrase; one work or passage per `add`; ask the owner one short question about intent if there is neither a note nor a hunch.
- Example call sequences (one command per line), e.g. `slowhunch add - --as poem --title "Trees" --author "Philip Larkin" --note "why it matters" --hunch <id>`, `slowhunch search "query" --limit 5 --json`, `slowhunch backlinks <id> --json`, `slowhunch get <id> --json` then `slowhunch update <id> --rev <rev> --data '{"tags":["x"]}'`, `slowhunch hunch add "question"`, `slowhunch hunch due`.
- Session shape: `skill` once → `verify` → work (add / search / hunch) → `verify` → answer the owner with `[[id]]` and exact quotes from the book only.
- Do not write the literal double-dash form of the add force flag anywhere (see Standing constraints); if you mention it, write `-force`.

Output: text mode prints the guide exactly; JSON mode returns `{"text": "<guide>"}`.

Test `TestSkill` in `internal/cli/cmd_skill_test.go`: at most 60 lines, contains `slowhunch verify`, `slowhunch add`, `slowhunch search`, `--json`, `[[id]]`; JSON mode has `"schema": 1` and a `text` key.
