## Brief
Add `internal/cli/cmd_add.go`, the test helper `internal/cli/fakemodel_test.go`, and `internal/cli/cmd_add_test.go`.

`add <text|file|-> [--as M] [--url U] [--title T] [--author A] [--note N] [--hunch ID] [-force]` plus global `--dry-run --no-commit --json --vault`:
- Open the vault and config (`env.openVault()`), import the providers for registration (`_ ".../internal/provider/openai"`, `_ ".../internal/provider/exec"`), build `Providers` with `provider.ForRole(cfg, role)` for gate, extract, place (an unknown provider or bad config → exit 1), `Prompts` with `provider.LoadPrompts(root)`, `Committer` = `gitops.New(root)` unless commit is disabled (`--no-commit`, `git.commit` false, git missing), `Author` = `agent:<provider name>/<model or "unknown">` from `provider.Effective(cfg, "extract")`.
- Call `pipeline.Add`; on error print the JSON error envelope and use its exit code. On success print the report: always JSON (also without `--json`), as `{"schema": 1, "ok": true, "run_id", "source", ...}` keeping the report's key order (the CLI envelope already splices result keys in order). Exit 0 even when the report contains item errors.
- Register the flag named `force` (users may type it with one or two dashes); the help/summary text writes it as `-force` (Standing constraints forbid the double-dash literal in non-test Go files).

Test helper (`fakemodel_test.go`, package `cli`):
- `TestMain(m)`: if `os.Args` contains `slowhunch-fake-model`, act as an `exec` provider and `os.Exit(0)` before `m.Run()`: read the request JSON `{role, medium, system, user, max_tokens}` from stdin; reply on stdout with `{"text": <json string>, "tokens_in": 10, "tokens_out": 5}` where the text is: gate `{"keep": true, "reason": "fake"}`; extract: take the lines between the delimiter lines in `user` (strip `N<TAB>` prefixes), use the first non-empty line as evidence; aesthetic media (poem lyric prose quote film art) → stance `crafts`, locator `line <its number>`; code → `lines N-N`; thread → `comment 1`; otherwise stance `asserts`, no locator, confidence 0.5; claim = `"Fake claim: "` + first 6 words; place → `{"verdict": "new", "target": "", "reason": "fake"}`.
- `func newFakeVault(t *testing.T) string`: temp dir, `Run(init)`, then rewrite `.slowhunch/config.json` so `provider` is `{"name": "exec", "command": [<os.Executable()>, "slowhunch-fake-model"]}` (commit that config change with git, or leave it: it was written by init and is not touched by add). Returns the vault path.

Tests (`cmd_add_test.go`): `TestAddCLIArticle` (stdin text via `-`, `--as article`: exit 0, JSON has `"schema": 1`, a source and at least one atom on disk, one new commit), `TestAddCLIPoem` (argument text, `--as poem --title Trees --author "Philip Larkin"`), `TestAddCLIErrors` (`.pdf` file → exit 2 UNSUPPORTED; 12,001 chars → exit 2 TOO_LONG; `--as film` without title → exit 2; unknown provider name in config → exit 1), `TestAddCLIDryRun` (tree unchanged), `TestAddCLIConflict` (dirty `--hunch` file → exit 4 CONFLICT).
