# T029: exec provider with scrubbed environment

Phase 5 · Model: opus: subprocess construction without a shell and environment scrubbing are security Risk items · Depends-on: T027 · Covers: R19 (exec), R18, R22 (secrets only via the named env var)

## Brief
Create package `execprov` in `internal/provider/exec/` (`exec.go` + `exec_test.go`). This is the only non-test file outside `internal/gitops` that may import `os/exec`.

API (exact):
```go
type Runner struct { Command []string; APIKeyEnv string; Timeout time.Duration }   // Timeout default 120 s
func New(cfg vault.ProviderConfig) (provider.Provider, error)    // cfg.Command must be non-empty with a non-empty argv[0], else errs.Fatal(errs.BadInput, ...)
func (r *Runner) Complete(ctx context.Context, req provider.Request) (provider.Response, error)
func init() { provider.Register("exec", New) }
```
Behaviour:
- Run `exec.CommandContext(ctx, Command[0], Command[1:]...)` directly: never `sh -c`, never string concatenation of arguments, never expanding `$VARS` or globs. `argv[0]` is resolved with the normal `exec.LookPath` rules.
- Environment is exactly `PATH=<current PATH>` plus, if `APIKeyEnv` is set and that variable is non-empty, `<APIKeyEnv>=<value>`. Nothing else (no HOME, no inherited vars). Build it from `os.Getenv`; `exec.go` must not call `os.Environ()` and must not contain the strings `"sh"`, `"bash"` or `"-c"`.
- Stdin: JSON `{"role", "medium", "system", "user", "max_tokens"}`. Stdout must be one JSON object `{"text": string, "tokens_in": int, "tokens_out": int}`; anything else → PROVIDER_ERROR. Stdout is capped at 1 MiB, stderr at 4 KiB.
- Timeout (`context.WithTimeout`, kill on expiry) → PROVIDER_ERROR. Non-zero exit → PROVIDER_ERROR whose message contains the exit code and at most 200 bytes of stderr, with the key value redacted to `***`.

Tests: use the test binary itself as the helper program, not a shell script (shells add variables such as PWD and SHLVL). In `exec_test.go`, `TestMain` checks `os.Args` for a marker such as `slowhunch-exec-helper <mode>` before `m.Run()` and, if present, acts as the helper and exits: mode `echo` reads the request and replies with `text` = the request's `role`+`|`+`user`; mode `env` replies with `text` = the sorted `os.Environ()` joined by `\n`; mode `bad` prints `not json`; mode `fail` writes to stderr and exits 3; mode `sleep` sleeps 5 s. The provider is configured with `Command: []string{<os.Executable()>, "slowhunch-exec-helper", "<mode>"}`.
`TestExecRoundTrip`, `TestExecScrubbedEnv` (with `t.Setenv("SLOWHUNCH_API_KEY","test-key")` and an unrelated `t.Setenv("OTHER_VAR","x")`: the helper sees exactly `PATH` and `SLOWHUNCH_API_KEY`), `TestExecNoShell` (an argument like `$(touch pwned)` or `;echo hi` reaches the helper verbatim and creates no file), `TestExecBadOutput`, `TestExecFailExit` (PROVIDER_ERROR mentions exit code), `TestExecTimeout` (Timeout 200 ms → PROVIDER_ERROR in well under 5 s), `TestExecEmptyCommand`.

## Verification
`.harness/verify/v1/T029.sh` exits 0. It runs the named tests and checks that `os/exec` is imported only by gitops and this package; negatives: an empty command is refused, and the source contains no shell invocation.
