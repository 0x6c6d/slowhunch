# T023: lint checks and command

Phase 4 · Model: sonnet: four mechanical rules over the index · Depends-on: T011, T013 · Covers: R16 (lint), R17 (exit 3)

## Brief
Add `internal/vault/lint.go` (pure checks) and `internal/cli/cmd_lint.go` + tests. Use `(*Vault).LoadIndex`, `(*Index).OfType/MediumOf`, `vault.IsAesthetic`, `frontmatter.LineOf`.

Shared problem type (also used by verify later):
```go
type Problem struct {
    ID      string `json:"id"`
    Path    string `json:"path"`
    Line    int    `json:"line"`   // 1-based line of the offending field in the file, 0 if not applicable
    Code    string `json:"code"`
    Message string `json:"message"`
}
func Lint(ix *Index, loadErrs []LoadError) []Problem   // sorted by path, then line, then code
```
Rules (one problem per violation per note):
- `MISSING_LOCATOR`: a note whose source medium (`MediumOf`) is aesthetic and whose `locator` is empty.
- `CONFIDENCE_NOT_ASSERTS`: a note with a non-empty `confidence` and `stance` ≠ `asserts`.
- `RENDERING_AS_EVIDENCE`: a note with non-empty `rendering` and (empty `evidence` or `rendering` == `evidence`).
- `READS_WITHOUT_REREADS`: a `reads` note R for which another note A exists with the same trimmed `evidence`, A created before R (same date → A's id sorts first), and R's `rereads` does not contain A's id.
- `BAD_FRONTMATTER`: each `LoadError` (id = file name without `.md`, line 0).

Command `lint`: read-only (no txn, no audit, nothing written). No problems → result `{"failures": [], "checked": <notes>}`, exit 0. Otherwise return `errs.New(errs.LintFailed, "<n> lint failures", "fix the listed files")` with `Extra{"failures": problems}` → exit 3; text mode prints one line per failure `path:line: CODE message`.

Tests: `internal/vault/lint_test.go` `TestLintRules` (each rule positive and negative), and `internal/cli/cmd_lint_test.go` `TestLintCommand` (clean vault exit 0; for each of the four violations a vault with exactly that violation exits 3, the JSON failure names the note id and code, and the vault tree hash is unchanged).
