# T001: Wikilink strip in Normalize + unit tests

Phase 1 · Model: sonnet: one function change plus table tests, moderate care for idempotence · Depends-on: T000 · Covers: R41, R42, R8

## Brief
File: `internal/intake/normalize.go` (func `Normalize(text, medium string) string`), tests in a new file `internal/intake/wikilink_test.go`.

Behaviour: for every medium except `code` (which keeps returning early, untouched), remove wikilink brackets. Use a package-level `regexp.MustCompile(`!?\[\[([^\[\]\n]+)\]\]`)` replaced by `$1`: `[[a]]`→`a`, `[[a|b]]`→`a|b` (inner text unchanged), `![[a]]`→`a`, `[[a#h]]`→`a#h`. Repeat the replacement until the text stops changing (so `[[[[a]]]]`→`a` and `Normalize` stays idempotent). Place the step after `normReplacer.Replace` and before the whitespace folding loop. Must NOT change: `[x]`, `[t](u)`, `[[` alone, `[[]]`, `[[a` newline `b]]`, any text in `code` medium (`m[[i]]` stays).

Tests (exact names): `TestWikilinkStrip` (table: `[[a]]`, `[[a|b]]`→`a|b`, `![[a]]`, two links on one line, `[[Blood Hound]]`→`Blood Hound`, `[[[[a]]]]`→`a`, and unchanged `[x]`, `[t](u)`, `[[`, `[[]]`, `"[[a\nb]]"`, all with medium `article`); `TestWikilinkCodeUntouched` (`Normalize("m[[i]] = 1", "code")` is unchanged, while `Normalize("m[[i]] = 1", "prose")` equals `mi = 1`), `TestWikilinkHash` (`TextHash(Normalize("see [[a]]","article")) != TextHash("see [[a]]")` and equals `TextHash("see a")`). Existing tests `TestNormalizeTable`, `TestNormalizeIdempotent` stay unchanged and green; add a wikilink input to the idempotence inputs in your new test file only (do not edit the old test).
